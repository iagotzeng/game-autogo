# 捏臉系統原型 v0.2

單檔 HTML（`index.html`），無建置步驟，直接用瀏覽器開啟即可。以《燕雲十六聲》的捏臉體驗為參考。

- **直接拖曳**：每個分區在臉上顯示金色控制點，拖曳即調整（顴骨、下顎、下巴、眉、眼、鼻、嘴、耳）。
- **左右非對稱**：關閉「左右對稱」後，眉、眼、耳可分別調整左右。
- **骨相 / 皮相分層**：骨相管輪廓；皮相管臥蠶、法令紋、眼尾紋、痣、雀斑。
- **妝容獨立分層**：眼影（色 + 濃度）、眼線、腮紅、唇色（色 + 濃度）、面靨。
- **光照與鏡頭**：左側 / 正面 / 右側光照；半身 / 臉部鏡頭。
- **撤銷 / 重做**（Ctrl+Z / Ctrl+Shift+Z）、按住對比原貌、隨機本區 / 全臉、重置本區。
- **臉譜庫**：六組宗門預設 + 本機儲存的臉譜（縮圖）。
- **分享捏臉數據**：`WD2.` 代碼 + 二維碼；相容舊版 `WD1.` 代碼。

正式版以 3D BlendShape 實作，此原型用來驗證分區、控制點與操作流程。
