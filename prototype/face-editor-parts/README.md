# 湊臉原型 v0.5（選件式）

單檔 HTML（`index.html`），直接用瀏覽器開啟即可。玩家從每個部位的多種款式中點選，拼出角色。

| 部位 | 款式 |
|---|---|
| 臉型 | 瓜子臉、鵝蛋臉、圓臉、方臉、長臉、菱形臉 |
| 眉型 | 劍眉、柳葉眉、平眉、粗眉、英氣眉、八字眉 |
| 眼型 | 鳳眼、桃花眼、杏眼、狹長眼、下垂眼、狐狸眼、圓眼、半闔眼 |
| 鼻型 | 挺鼻、小巧鼻、鷹鉤鼻、圓鼻、高山根 |
| 嘴型 | 冷峻、微笑、抿唇、薄唇、厚唇、淺笑露齒 |
| 前髮 | 中分、斜瀏海、齊瀏海、露額、碎髮、三七分、垂髮遮眼、光頭 |
| 後髮 | 道髻長髮、高馬尾、披髮、短髮、半束髮、光頭 |
| 髮飾 | 銀簪、玉簪、金冠、髮帶 |
| 紋飾 | 冰晶花鈿、朱砂、金印、眉心道紋、雙頰道紋、左眼疤 |
| 鬚與斑 | 山羊鬍、八字鬍、絡腮鬍、面靨、雀斑 |
| 顏色 | 膚色 6 種、髮色 10 種、瞳色 8 種，皆可自訂 |
| 服飾 | 六大宗派道袍、八種靈根氣息、金丹光環 |

每個款式在面板上都有即時縮圖預覽；另有臉部 / 半身鏡頭、撤銷重做、對比原貌、隨機、臉譜庫與 `WD5.` 數據二維碼分享。
