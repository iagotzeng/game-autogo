# 原畫變形捏臉原型 v0.4（2.5D）

用 Gemini 出圖的青雲劍修原畫當底，以 MediaPipe Face Mesh 偵測 478 個臉部關鍵點，建立帶深度的變形網格；滑桿與控制點直接變形原畫，妝容與瞳色以圖層混合疊上去。畫面就是原畫的品質。

- `index.html`：單檔成品（原畫與關鍵點已內嵌），從 cdnjs 載入 three.js r128 與 qrcodejs。
- `template.html`：範本，`__IMG__` 與 `__LM__` 由建置腳本填入。
- 換圖流程：對新圖執行 MediaPipe Face Mesh 取得關鍵點 → 裁切上半身 → 填入範本。臉部越大的圖效果越好，建議用半身特寫。

功能：骨相（臉長、臉寬、下顎、下巴、顴骨、眉弓、眼窩）、眉、眼（含瞳色）、鼻、嘴、皮相（膚色、腮紅、痣、雀斑）、髮色、妝容（眼影、唇色）、紋飾（額飾、道紋、疤痕）；正面 / 微側視角與臉部 / 半身 / 全景鏡頭；撤銷重做、對比原貌、隨機、臉譜庫、`WD4.` 數據與二維碼分享。

限制：只能小幅轉頭（約 ±20 度）；來源圖的臉約 120 像素寬，臉部特寫會偏軟。
