# 換裝捏臉原型 v0.6（2D 圖層合成）

單檔 HTML（`index.html`），直接用瀏覽器開啟。依企劃案 4.3「2D 分層換裝式」實作：

- **圖層**（由後到前）：背景、後髮、身體、臉型、眼睛、眉毛、鼻子、嘴巴、鬚斑、紋飾、前髮、髮飾、特效。
- **選件**：每層多款，右側縮圖格點選即換。內建款式為程式繪製的占位配件（由 `renderer.js` 逐層向量繪製後點陣化）。
- **微調**：每層可調大小（60–150%）、水平 / 垂直位置（±60）、角度（±20°）；眼睛與眉毛另有間距（±30）。
- **匯入真實素材**：把 imagegen 或美術產出的透明 PNG 拖進預覽區，或在「素材」分頁選檔。檔名前綴決定圖層（`hairfront_`、`hairback_`、`eyes_`、`brow_`、`nose_`、`mouth_`、`face_`、`pin_`、`mark_`、`extra_`、`body_`、`bg_`），辨識錯可改。素材存於瀏覽器 IndexedDB。
- **保存 / 隨機 / 復原**：臉譜庫（含縮圖）、隨機本部位、隨機全臉、撤銷重做、按住對比原貌、`WD6.` 數據與二維碼分享、匯出 PNG（1200×1520）。

## 檔案
- `template.html`：頁面範本；`renderer.js`：占位配件的向量繪製；`index.html`：兩者組合後的成品。
- 重新組合：把 `renderer.js` 內容替換範本中的 `__RENDERER__`。

## 素材規格
基準畫布 1200×1520（4:5）。配件置中、正面、透明 PNG；匯入後以該部位的預設框寬度縮放，再用微調對位。詳細提示詞見 `docs/concept/素材製作指南.md`。
