# 立體捏臉原型 v0.3（Three.js）

單檔 HTML（`index.html`），從 cdnjs 載入 three.js r128 與 qrcodejs，直接用瀏覽器開啟即可。

- **程式生成的風格化頭模**：以球面位移場建構，臉長、臉寬、頭深、下顎、下巴、顴骨、眉弓、眼窩、鼻梁、鼻頭、唇部立體都是真正的 3D 變形，可轉頭觀看。
- **貼圖層五官**：眉、眼、嘴、妝容、紋飾、瀏海畫在臉部貼圖上（動漫 3D 常見作法），眼窩與鼻梁的 3D 起伏會跟著眼位、鼻位移動。
- **卡通著色加墨線描邊**：三階卡通漸層與反向外殼描邊，對應企劃案的水墨風格化 3D。
- **髮片式頭髮**：四十多條沿頭骨生成的髮片（動漫 3D 常見的 hair card 作法），髮片貼圖自帶墨線邊緣與高光；瀏海四款（中分、斜、齊、無）、長髮、側髮、隨風飄動髮束、道髻與髮簪。
- **手繪式陰影**：臉部貼圖畫上下顎、太陽穴、鼻側、唇下的柔和陰影與額頭高光，讓卡通著色有立體感。
- **上半身**：肩線、寬袖、交領（布帶式）、腰帶與結扣。
- **場景元素**：宗門道袍與交領、靈根氣息、金丹光環、萬劍朝宗劍陣、水墨遠山背景。
- **操作**：正面時可拖曳金色控制點；拖曳空白處轉頭、滾輪縮放；正面 / 側四十五 / 側面與臉部 / 半身鏡頭；光照三向；撤銷重做、對比原貌、隨機、臉譜庫（3D 渲染縮圖）、`WD3.` 數據與二維碼分享。

## 與正式版的差距
- 正式版應改用美術製作的頭模與 BlendShape，這裡的程式生成頭模只用來驗證流程與手感。
- 尚未做左右非對稱與體型。
