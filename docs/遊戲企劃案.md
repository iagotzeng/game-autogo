## 1. 專案概述

### 1.1 一句話介紹

**在八人論道的棋局中，招募修士、突破境界、渡過天劫，成就唯一的飛升者。**

### 1.2 核心概念

《問道棋局》是一款以東方修仙為題材的自走棋（Auto Battler）。玩家扮演一位開宗立派的 **宗主**，在每回合的準備階段招募修士、佈陣、修煉功法，戰鬥階段則由修士自動對戰。

與傳統自走棋最大的差異在於：**「成長」不只是三合一升星，而是修仙世界觀下的完整體系** —— 修士要突破境界、要渡天劫、會生心魔；宗主本身也在修煉，境界越高能派出的修士越多。每一局都是一段從煉氣散修到渡劫飛升的修仙旅程。

### 1.3 基本資訊

| 項目 | 內容 |
|---|---|
| 遊戲類型 | 自走棋 / 策略 / 輕度 Roguelike 元素 |
| 題材 | 東方修仙、仙俠 |
| 目標平台 | 第一階段：PC（Steam）；第二階段：iOS / Android（跨平台同步） |
| 遊玩人數 | 8 人論道（標準）、4 人雙修（2v2）、單人閉關（PvE） |
| 單局時長 | 25 – 35 分鐘 |
| 營運模式 | 免費遊玩 + 外觀付費（不賣數值） |
| 美術風格 | 水墨風 3D 低模（Stylized Low-poly + Ink Shader） |
| 目標分級 | 12+ |

### 1.4 目標客群

- **核心客群**：熟悉《雲頂之弈》《金鏟鏟之戰》《刀塔自走棋》，追求策略深度與陣容變化的玩家（20–35 歲）。
- **次要客群**：修仙小說、仙俠遊戲愛好者，被題材吸引後透過低門檻上手留下。
- **潛在客群**：喜歡 Roguelike 構築（《殺戮尖塔》《吸血鬼倖存者》）的玩家，被單人閉關模式吸引。

### 1.5 核心賣點（USP）

1. **境界突破取代升星**：三名同修士合一即「突破」，但高境界突破需「渡劫」，成功則額外強化、失敗則損傷，帶來風險決策。
2. **宗主也在修煉**：玩家自身有境界與靈根，會影響商店刷新、羈絆加成與獨有的宗主神通。
3. **功法與法寶的裝備體系**：裝備分「功法」（改變技能行為）與「法寶」（數值與特效），功法可與修士靈根共鳴產生變體技能。
4. **秘境探索與天劫事件**：PvE 回合不只是打怪拿裝備，而是選擇進入不同秘境，獲得對應類型的機緣。
5. **心魔機制**：連勝、連敗、過度貪婪都可能誘發心魔，讓局勢反轉，增添戲劇性與翻盤空間。

## 2. 設計支柱

所有設計決策以下面四根支柱為判斷依據，衝突時依序取捨：

| 順序 | 支柱 | 說明 |
|---|---|---|
| 1 | **每局都是一段修仙故事** | 玩家從煉氣到飛升的過程要有清楚的階段感、事件感與敘事感，而不只是數值堆疊。 |
| 2 | **決策深度高於操作** | 自走棋的樂趣在決策：買誰、賣誰、何時升級、何時渡劫。避免加入需要手速的機制。 |
| 3 | **風險與機緣並存** | 修仙世界「富貴險中求」，重要成長都要有可選擇的風險（渡劫、心魔、秘境），並讓玩家清楚知道機率。 |
| 4 | **易學難精** | 新手 3 局內看懂羈絆與突破；老手在功法搭配與天劫時機上持續鑽研。 |

## 3. 世界觀與美術方向

### 3.1 世界觀

- **世界名**：九州靈界。
- **背景**：千年一度的「**問道大會**」開啟，天道降下「**道基**」給各方宗主。宗主們在大會的「**論道棋局**」中派出門下修士切磋，落敗者道基受損，道基盡毀者失去問道資格；最後留存者將得到唯一的飛升名額。
- **敘事定位**：局內敘事以短句與事件文本呈現（秘境介紹、天劫描述、心魔獨白），不強制劇情，不打斷節奏。
- **地圖 / 場景**：棋盤即「論道台」，四周隨局勢階段變化：煉氣期是山門石台、金丹期是雲海仙島、渡劫期是雷雲密佈。

### 3.2 門派設定（八大門派）

| 門派 | 定位 | 風格關鍵字 |
|---|---|---|
| 劍宗 | 高單體爆發、前排 | 御劍、劍氣、白衣 |
| 丹閣 | 治療、增益 | 丹爐、藥香、青衫 |
| 符門 | 遠程法傷、控制 | 符籙、陣法、黃紙 |
| 體修 | 坦克、反傷 | 金身、鐵骨、赤膊 |
| 魔道 | 吸血、生命交換 | 血煞、黑袍、詭異 |
| 佛門 | 護盾、淨化 | 金光、袈裟、梵音 |
| 妖族 | 變身、後期成長 | 獸形、靈氣、野性 |
| 散修 | 靈活、萬用 | 樸素、機緣、隨機 |

### 3.3 美術方向

- **整體**：水墨風格化 3D，低多邊形模型搭配墨線描邊 Shader，色彩以留白與少量高飽和點綴（劍光、丹火、雷劫）。
- **棋子辨識**：每個門派固定一個主色與剪影特徵（劍宗背劍、丹閣持爐、佛門光環），確保縮圖下仍可辨識。
- **境界視覺**：突破後模型不換、但加上「境界光效」（煉氣無光效、築基淡光、金丹金環、元嬰身後虛影），一眼看出強度。
- **UI**：宣紙底色、朱印按鈕、豎排標題，但功能區維持現代橫向布局以確保可讀性。

### 3.4 音樂音效

- BGM：古箏、簫、鼓為主，依階段從清幽轉向緊張。
- 音效關鍵：突破成功的「鐘鳴」、渡劫的「雷擊」、心魔的「低語」須有極高辨識度，是玩家情緒的錨點。

## 4. 核心玩法循環

### 4.1 單局結構

一局共 **6 個階段（紀元）**，每階段 4 – 6 回合，總計約 30 回合。

| 階段 | 名稱 | 回合數 | 內容 |
|---|---|---|---|
| 一 | 入門 | 1-1 ~ 1-4 | PvE 練功（打靈獸），取得基礎法寶素材，選擇初始靈根 |
| 二 | 煉氣 | 2-1 ~ 2-6 | 開始 PvP 論道，2-4 為第一次秘境 |
| 三 | 築基 | 3-1 ~ 3-6 | 3-4 秘境；羈絆成形期 |
| 四 | 金丹 | 4-1 ~ 4-6 | 4-4 秘境；首次天劫（4-6） |
| 五 | 元嬰 | 5-1 ~ 5-6 | 5-4 秘境；心魔高發期 |
| 六 | 渡劫 | 6-1 ~ 結束 | 每回合傷害大幅提升，快速決出勝負 |

### 4.2 回合流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  準備階段     │ →  │  戰鬥階段     │ →  │  結算階段     │ →  │  事件階段     │
│  (30 秒)     │    │  (≤ 60 秒)   │    │  (5 秒)      │    │  (視情況)     │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
 招募 / 佈陣 /        自動對戰            扣道基 / 發靈石      秘境 / 天劫 /
 突破 / 修煉 /                            / 連勝連敗結算       心魔 / 機緣
 宗主修煉
```

- **準備階段（30 秒）**：花靈石買修士、賣修士、擺放棋盤（4×7 己方半場）、宗主修煉（升等）、刷新商店、裝備功法法寶。
- **戰鬥階段（最長 60 秒）**：與隨機對手鏡像對戰，超時由剩餘總生命比例判定。
- **結算階段**：敗方依存活敵方修士數量與境界扣道基；發放基礎靈石、利息、連勝/連敗獎勵。
- **事件階段**：秘境回合、天劫回合或心魔觸發時進入，其他回合略過。

### 4.3 勝負條件

- 每位宗主初始 **道基 100**。
- 道基歸零即出局；最後存活者勝。
- 排名 1–4 為「得道」（正分），5–8 為「道損」（負分）。

## 5. 棋子系統：修士

### 5.1 修士基本屬性

| 屬性 | 說明 |
|---|---|
| 費用 | 1 – 5 靈石，對應稀有度 |
| 門派 | 1 – 2 個（決定門派羈絆） |
| 靈根 | 1 個（金木水火土 / 雷），決定靈根羈絆與功法共鳴 |
| 生命 | 基礎值，突破後倍增 |
| 攻擊 | 基礎值，突破後倍增 |
| 攻速 | 每秒攻擊次數 |
| 護體 / 道心 | 對應物理 / 法術減傷 |
| 靈力 | 相當於法力值，滿時釋放神通（技能） |
| 攻擊距離 | 1 格近戰 ~ 5 格遠程 |
| 神通 | 每名修士的主動技能 |

### 5.2 境界（取代星級）

| 境界 | 等同星級 | 取得方式 | 屬性倍率 |

| 煉氣 | ★ | 商店購買 | 1.0× |

| 金丹 | ★★★ | 3 名築基合一（自動） | 3.2× |
| 元嬰 | ★★★★ | 金丹 + 通過天劫，或特殊機緣 | 5.5× |

## 6. 羈絆系統：門派與靈根

### 6.1 門派羈絆（8 種）

上場相同門派修士達到門檻時啟動。門檻通常為 2 / 4 / 6。

| 門派 | 2 名 | 4 名 | 6 名 |
|---|---|---|---|
| 劍宗 | 劍宗攻擊 +15% | +35%，攻擊有 20% 機率觸發劍氣濺射 | +60%，每次擊殺永久 +5% 攻擊（本局） |
| 丹閣 | 全隊每 3 秒回復 2% 生命 | 4%，且治療量 +30% | 6%，且友軍死亡時掉落丹藥復活（一場一次） |
| 符門 | 符門法傷 +20% | +45%，神通命中額外眩暈 0.5 秒 | +80%，戰鬥開始時佈下陣法，敵方前排減速 |
| 體修 | 體修護體 +20 | +45，受傷反彈 10% | +80，反彈 25%，免疫控制 |
| 魔道 | 魔道攻擊吸血 20% | 35%，殺敵時獲得永久生命上限 | 50%，生命低於 30% 時進入「魔化」狀態 |
| 佛門 | 全隊開場護盾 10% 生命 | 20%，每 5 秒淨化負面效果 | 35%，佛門修士死亡時為全隊治療 |
| 妖族 | 妖族修士每 10 秒屬性 +10% | 每 8 秒 +15% | 每 6 秒 +20%，戰鬥 30 秒後全體妖化 |
| 散修 | 散修修士隨機獲得一個其他門派 2 名效果 | 4 名效果 | 每名散修隨機獲得兩個 |

### 6.2 靈根羈絆（6 種）

| 靈根 | 3 名 | 5 名 | 說明 |
|---|---|---|---|
| 金 | 暴擊率 +15% | +30%，暴擊傷害 +50% | 攻擊型 |
| 木 | 治療與護盾 +20% | +45% | 續航型 |
| 水 | 神通冷卻 / 靈力回復 +20% | +45% | 施法型 |
| 火 | 神通傷害 +20% | +45%，附帶灼燒 | 爆發型 |
| 土 | 生命上限 +15% | +35%，免疫擊退 | 坦克型 |
| 雷 | 攻速 +15% | +35%，攻擊附帶麻痺 | 極端型（雷靈根修士稀少） |

### 6.3 五行相生相剋（進階系統）

- **相生**：金→水→木→火→土→金。當場上同時有相生的兩種靈根羈絆啟動時，被生者效果 +20%。
- **相剋**：金剋木、木剋土、土剋水、水剋火、火剋金。對局中若敵方主靈根為你的被剋方，你的靈根羈絆效果 +10%（提供陣容克制的閱讀空間，但幅度不大以免過度隨機）。
- 此系統在教學模式中預設關閉，排位開啟。

### 6.4 宗主靈根

- 每局開局（1-2）可從三個隨機靈根中選擇一個作為「宗主靈根」。
- 效果：該靈根修士在商店出現機率 +8%；該靈根羈絆門檻 -1。
- 提供一開局就有的方向感，減少純隨機開局的挫折。

## 7. 修仙成長系統

這是本作區別於其他自走棋的核心。成長分三層：**修士成長、宗主成長、功法法寶**。

### 7.1 修士成長：突破與渡劫

#### 突破（煉氣→築基→金丹）
- 沿用三合一自動合成。
- 合成時播放「突破」演出（1 秒），突破後保留已裝備的功法法寶（超出上限退回背包）。

#### 渡劫（金丹→元嬰）
- 只在 **天劫回合**（4-6、5-6、6-3）可執行。
- 每回合最多渡劫 1 名修士。
- 基礎成功率 60%，可透過以下方式提升：
  - 裝備「護劫法寶」+15%
  - 丹閣羈絆 4 名以上 +10%
  - 宗主境界元嬰以上 +10%
  - 上限 95%（永遠留一點天意）。
- **成功**：升為元嬰，隨機獲得一個「劫後神通」（如：復活一次、免疫控制、神通雙發）。
- **失敗**：退回築基，但獲得 3 靈石補償與「道心堅定」標記（下次渡劫 +20%）。
- 設計目的：把「要不要冒險」的決策交給玩家，並讓後期有翻盤點。

### 7.2 宗主成長：修為與境界

相當於一般自走棋的玩家等級，但包裝為宗主修煉。

| 宗主境界 | 上場人數 | 所需修為 | 解鎖 |
|---|---|---|---|
| 煉氣 | 3 | 0 | — |
| 築基 | 4 | 4 | — |
| 金丹 | 5 | 10 | 宗主神通一 |
| 元嬰 | 6 | 20 | — |
| 化神 | 7 | 36 | 宗主神通二 |
| 煉虛 | 8 | 56 | — |
| 合體 | 9 | 80 | 宗主神通三 |
| 渡劫 | 10 | 120 | 上場人數上限 |

- 每回合自動 +2 修為；花 4 靈石可購買 4 修為（「閉關」）。
- **宗主神通**：三個階段各從三選一中挑一個被動，例如：
  - 金丹期：「識人之明」（商店每次刷新保底一名當前主門派修士）、「點石成金」（利息上限 +2）、「護短」（前排修士護體 +10）。
  - 化神期：「天機」（可預覽下一回合對手）、「煉器」（每 3 回合送一件法寶素材）、「悟道」（隨機一個羈絆門檻 -1）。
  - 合體期：「化身」（複製一名金丹以下修士）、「逆命」（渡劫失敗不降級）、「宗門大陣」（戰鬥開始全隊護盾 15%）。

### 7.3 功法與法寶

#### 法寶（Items，數值型）
- 由秘境、PvE 回合掉落「**素材**」（如：精鐵、靈玉、妖丹、雷木），兩件素材合成一件法寶。
- 每名修士最多攜帶 3 件。
- 範例：
  - 精鐵 + 精鐵 = 玄鐵重劍（攻擊 +30%）
  - 靈玉 + 妖丹 = 護心鏡（受到致死傷害時護盾一次）
  - 雷木 + 精鐵 = 雷鳴劍（攻擊附帶雷擊，跳躍 2 名敵人）
- 首版目標：8 種素材、36 種合成法寶。

#### 功法（Techniques，行為型）
- 稀有取得（秘境深層、天劫回合、宗主神通），每名修士最多 1 本。
- 功法**改變神通的行為**而非數值，例如：
  - 《御劍訣》：御劍類神通改為攻擊最近敵人並可穿透。
  - 《噬魂經》：任何神通造成的傷害 50% 轉為治療自己。
  - 《太上忘情》：神通改為無需靈力，每 6 秒自動釋放但傷害 -40%。
- **靈根共鳴**：功法有屬性，與修士靈根相同時，效果強化（例如《焚天訣》給火靈根修士時額外附帶灼燒）。
- 首版目標：12 本功法。

### 7.4 成長曲線設計目標

| 階段 | 玩家感受 | 主要成長來源 |
|---|---|---|
| 入門 / 煉氣 | 摸索方向、蒐集素材 | 買 1–2 費修士、第一件法寶 |
| 築基 | 陣容雛形、羈絆啟動 | 三合一築基、宗主境界金丹 |
| 金丹 | 主 C 出現、法寶到位 | 4 費修士、法寶 3 件、宗主神通一 |
| 元嬰 | 渡劫決策、功法搭配 | 元嬰修士、功法共鳴、宗主神通二 |
| 渡劫 | 拼最後一口氣 | 5 費修士、劫後神通、心魔翻盤 |

## 8. 經濟與商店

### 8.1 靈石（貨幣）

- 每回合基礎收入：5 靈石。
- **利息**：每持有 10 靈石 +1，上限 +5（50 靈石）。
- **連勝 / 連敗**：2–3 連 +1、4–5 連 +2、6+ 連 +3。
- 勝利額外 +1。
- PvE 回合掉落素材而非靈石。

### 8.2 商店

- 每回合自動刷新 5 個欄位；手動刷新 2 靈石。
- 可鎖定商店。
- **出現機率依宗主境界變化**（見附錄表 18.1）。
- **宗主靈根加成**：對應靈根修士出現機率 +8%。

### 8.3 賣出

- 煉氣修士賣出回收原價。
- 築基 / 金丹賣出回收「合成所耗總價 - 1」（小懲罰，避免無腦拆合）。
- 元嬰修士賣出回收金丹價，劫後神通消失。

### 8.4 經濟策略空間

- **攢息流**：早期吃利息，中期一波升級。
- **連敗流**：故意輸養連敗收入，同時累積素材。
- **快升級流**：早升宗主境界搶 4 費修士。
- **渡劫賭徒流**：全力堆渡劫成功率，靠元嬰翻盤。

## 9. 戰鬥系統

### 9.1 棋盤

- 六角格棋盤，8 列 × 7 行；己方 4 列、敵方 4 列（鏡像）。
- 備戰區 9 格。

### 9.2 戰鬥規則

- 修士自動尋敵：預設攻擊「射程內最近敵人」，特殊神通可改變目標邏輯。
- 攻擊累積靈力，受傷也累積靈力；靈力滿時釋放神通並歸零。
- 戰鬥最長 60 秒，超時比較雙方剩餘總生命百分比，高者勝，但敗方扣道基減半。

### 9.3 傷害公式

```
物理傷害 = 攻擊 × (1 + 攻擊加成) × 暴擊倍率 × 100 / (100 + 護體)
法術傷害 = 神通基礎值 × (1 + 法傷加成) × 100 / (100 + 道心)
真實傷害 = 不受護體 / 道心影響
```

- 護體 / 道心採用「有效減傷遞減」公式，避免堆疊無限收益。

### 9.4 道基扣除

```
扣除量 = 階段基礎傷害 + Σ(存活敵方修士境界傷害)
```

| 階段 | 基礎傷害 | 煉氣 | 築基 | 金丹 | 元嬰 |
|---|---|---|---|---|---|
| 二 | 0 | 1 | 2 | 3 | 5 |
| 三 | 2 | 1 | 2 | 3 | 5 |
| 四 | 4 | 2 | 3 | 4 | 6 |
| 五 | 6 | 2 | 3 | 5 | 8 |
| 六 | 10 | 3 | 5 | 7 | 10 |

### 9.5 戰鬥確定性

- 戰鬥必須是**確定性模擬**（相同輸入、相同種子 → 相同結果），伺服器與客戶端跑同一份邏輯，客戶端只負責演出。
- 所有隨機使用局內固定種子的 PRNG，禁止使用系統時間或浮點非確定運算。

## 10. 局內事件：秘境、天劫、心魔

### 10.1 秘境（每階段第 4 回合）

- 取代傳統的 PvE / 選秀回合。
- 玩家從 **三個秘境中選一個進入**（全體玩家同時選，各自獨立結算）：

| 秘境 | 風險 | 獎勵傾向 |
|---|---|---|
| 藥王谷 | 低：打靈獸 | 素材 ×2、有機率丹藥（回復道基 10） |
| 劍塚 | 中：打劍靈 | 攻擊向法寶素材、有機率功法 |
| 幽冥淵 | 高：打魔物，戰敗多扣道基 | 保底一本功法或一名 4 費修士 |
| 機緣閣 | 無戰鬥 | 從三個隨機「機緣」中選一個（局內 Roguelike 增益，如「本局每回合多 1 靈石」「渡劫 +10%」） |

- 每次隨機三個秘境出現，總池約 10 種，讓每局選擇不同。

### 10.2 天劫回合（4-6、5-6、6-3）

- 該回合 PvP 前，玩家可選 1 名金丹修士渡劫（見 7.1）。
- 全體玩家同時演出雷劫，成功 / 失敗會廣播給所有玩家（社交壓力與情緒高點）。
- 不渡劫者獲得 2 靈石「避劫」補償。

### 10.3 心魔（動態事件）

觸發條件（任一）：
- 連勝 ≥ 5：「驕心」— 下回合隨機一名修士攻擊 -30%。
- 連敗 ≥ 5：「怯心」— 下回合隨機一名修士無法釋放神通；但同時獲得「破而後立」：若該回合獲勝，全隊永久 +5% 屬性。
- 靈石 ≥ 70 持續 3 回合：「貪心」— 利息暫時歸零 2 回合。
- 渡劫連續失敗 2 次：「執念」— 下一次渡劫必定成功，但該修士生命 -20%。

設計原則：**心魔永遠附帶一個對應的機會**，讓它是戲劇轉折而非純懲罰。

## 14. 技術架構建議

> 本節為建議，最終選型待技術評估。

### 14.1 引擎

| 選項 | 優點 | 缺點 |
|---|---|---|
| **Godot 4（C#）** | 開源免授權、輕量、2D/3D 皆可、社群成長快 | 手機端與大型專案案例較少 |
| Unity | 成熟、資源多、跨平台穩定 | 授權費、風格化渲染需自製 |

建議：**原型階段用 Godot 4 + C#**，決定性戰鬥邏輯寫成獨立的 .NET 類別庫（無引擎依賴），伺服器可直接複用同一套程式碼。

### 14.2 系統分層

```
┌────────────────────────────────────────────────────────┐
│ 客戶端 (Godot)                                          │
│  UI / 演出 / 輸入  ←→  戰鬥重播器 (讀模擬結果播動畫)      │
└───────────────┬────────────────────────────────────────┘
                │ WebSocket (指令 / 狀態同步)
┌───────────────▼────────────────────────────────────────┐
│ 對局伺服器 (.NET)                                        │
│  房間管理 / 回合狀態機 / 商店 / 經濟                        │
│  ┌──────────────────────────────────────────────────┐   │
│  │ Core.Simulation (純 C#，無引擎依賴)                 │   │
│  │  棋盤 / 修士 / 羈絆 / 神通 / 傷害 / 確定性 PRNG      │   │
│  └──────────────────────────────────────────────────┘   │
└───────────────┬────────────────────────────────────────┘
                │
┌───────────────▼────────────────────────────────────────┐
│ 後端服務：帳號 / 配對 / 排位 / 資料表 (JSON/CSV 熱更新)    │
└────────────────────────────────────────────────────────┘
```

### 14.3 資料驅動

- 修士、羈絆、法寶、功法、秘境、心魔全部以資料表（JSON 或 CSV）定義，企劃可在不改程式的情況下調整。
- 神通行為以「效果節點」組合（例：`DealDamage → ApplyStatus → Heal`），減少每個技能硬寫程式。

### 14.4 平衡工具

- 建立**無頭模擬器**：讓 AI 陣容互打數千場，輸出羈絆勝率、修士出場率，作為平衡依據。
- 這是資料驅動 + 純邏輯核心的直接收益，應列為原型階段的產出之一。

## 17. 風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| 系統過多，新手看不懂（境界 + 渡劫 + 功法 + 心魔） | 上手率低 | 教學分段解鎖；閉關模式先用簡化規則；排位前 5 局關閉心魔與五行相剋 |

| 修仙題材在非華語市場認知度低 | 海外推廣困難 | 首版聚焦華語市場；視覺與機制設計避免依賴文字理解 |
