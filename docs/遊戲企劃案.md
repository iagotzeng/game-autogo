## 1. 專案概述

### 1.1 一句話介紹

**捏出你的修士、擲骰定下一生的靈根、拜入金丹宗派，在八人論道的棋局中招募道友、突破境界、渡過天劫，成就唯一的飛升者。**

### 1.2 核心概念

《問道棋局》是一款以東方修仙為題材的自走棋（Auto Battler）。玩家首次進入遊戲時 **創建屬於自己的修士角色**（捏臉、道號、出身），並 **擲骰決定一生的靈根命格**，再依命格分配屬性點。之後每一局都是一段新的入道之旅：

1. **命格定調**：你的靈根（天靈根、上品單靈根、中品雙靈根……五行雜靈根）與屬性決定了擅長的方向；局外可靠丹藥開靈根、洗髓，但代價陡升。
2. **入宗拜師**：在幾大金丹宗派中選擇一派，再從該派的山長、洞主中拜一位為師。師父擅長的流派（劍修、丹修、符修、體修……）決定你的起手方向。
3. **論道棋局**：在準備階段招募道友、佈陣、修煉功法，戰鬥階段由道友自動對戰。玩家角色以「本命化身」親自站上棋盤。
4. **修仙成長**：道友要突破境界、渡天劫；玩家自身也在修煉，境界越高能帶的道友越多。

與傳統自走棋的差異在於：**你帶著自己的命格入局，每局都是一次抉擇**；**成長不是三合一升星，而是修仙世界觀下的完整體系**，而且延伸到局外的靈根成長。

### 1.3 基本資訊

| 項目 | 內容 |
|---|---|
| 遊戲類型 | 自走棋 / 策略 / 輕度 Roguelike 元素 |
| 題材 | 東方修仙、仙俠 |
| 目標平台 | 第一階段：PC（Steam）；第二階段：iOS / Android（跨平台同步） |
| 遊玩人數 | 8 人論道（標準）、4 人雙修（2v2）、單人閉關（PvE） |
| 單局時長 | 25 – 35 分鐘（含開局入宗拜師約 1 分鐘） |
| 營運模式 | 免費遊玩 + 外觀付費（不賣數值、不賣丹藥） |
| 美術風格 | 水墨風 3D 低模（Stylized Low-poly + Ink Shader），角色支援捏臉 |
| 目標分級 | 12+ |

### 1.4 目標客群

- **核心客群**：熟悉《雲頂之弈》《金鏟鏟之戰》《刀塔自走棋》，追求策略深度與陣容變化的玩家（20–35 歲）。
- **次要客群**：修仙小說、仙俠遊戲（《鬼谷八荒》《了不起的修仙模擬器》）愛好者，被「擲靈根、拜師、捏臉」的修仙開局吸引。
- **潛在客群**：喜歡 Roguelike 構築（《殺戮尖塔》）的玩家，被單人閉關模式吸引。

### 1.5 核心賣點（USP）

1. **一生一次的天道測靈**：創角時擲骰決定靈根命格，天靈根的狂喜與五行雜靈根的逆天改命都是角色的故事；靈根越純自配點越少，雜靈根點數最多，起點公平、路數不同。
2. **靠丹藥開靈根**：局外煉丹開第二、第三靈根與洗髓提升品階，代價陡升，是長線目標。
3. **宗派與師承**：選宗派、拜山長或洞主，師父擅長多種流派時，能開出別人沒有的組合。
4. **你的角色親自上場**：捏臉創建的修士以「本命化身」站在棋盤上，隨境界成長，神通來自靈根與師承。
5. **境界突破取代升星**：三合一即突破，金丹升元嬰需渡劫，成功額外強化、失敗損傷。
6. **秘境、天劫、心魔**：局內事件讓每局有清楚的階段感與翻盤點。

## 2. 設計支柱

| 順序 | 支柱 | 說明 |
|---|---|---|
| 1 | **每局都是一段修仙故事** | 從入宗拜師、煉氣到飛升，要有清楚的階段感、事件感與敘事感；局外的靈根成長則是角色的長篇故事。 |
| 2 | **決策深度高於操作** | 買誰、賣誰、拜誰為師、何時渡劫。不加入需要手速的機制。 |
| 3 | **風險與機緣並存** | 渡劫、秘境都有可選擇的風險，機率永遠對玩家透明。 |
| 4 | **命格不同，路數不同，總量相當** | 靈根越純自配點越少，雜靈根點數最多；創角時命格評分相同。局外成長改變方向與廣度，配對依命格評分分層，成長不是碾壓新手的資本。 |
| 5 | **易學難精** | 新手 3 局內看懂靈根、流派與突破；老手鑽研師承搭配、功法共鳴與天劫時機。 |

## 3. 世界觀與美術方向

### 3.1 世界觀

- **世界名**：九州靈界。
- **修仙格局**：九州修為以金丹為巔峰，能結成金丹者方可開宗立派，故稱「**金丹宗派**」。宗派內部依山頭分治：**山長** 執掌一峰、學貫數脈；**洞主** 據一洞天、專精一藝。
- **背景**：千年一度的「**問道大會**」開啟，天道降下「**道基**」給各派弟子。弟子們在「**論道棋局**」中集結道友切磋，落敗者道基受損，道基盡毀者失去問道資格；最後留存者將得到唯一的飛升名額。
- **玩家身份**：一名初入道途的年輕修士。創角時的「天道測靈」定下一生靈根，每局入宗拜師後踏上棋局；局外靠丹藥開靈根、洗髓，走一條漫長的成長路。
- **敘事定位**：局內敘事以短句與事件文本呈現（測靈結果、師父評語、秘境介紹、天劫描述、心魔獨白），不強制劇情，不打斷節奏。
- **場景**：棋盤即「論道台」，四周隨局勢階段變化：煉氣期是山門石台、金丹期是雲海仙島、渡劫期是雷雲密佈。

### 3.2 八大流派（修煉路數）

流派是修煉的路數，跨宗派存在。每名道友有 1–2 個流派，山長 / 洞主各自擅長 1–3 個流派。

| 流派 | 定位 | 風格關鍵字 |
|---|---|---|
| 劍修 | 高單體爆發、前排 | 御劍、劍氣、白衣 |
| 丹修 | 治療、增益 | 丹爐、藥香、青衫 |
| 符修 | 遠程法傷、控制 | 符籙、陣法、黃紙 |
| 體修 | 坦克、反傷 | 金身、鐵骨、赤膊 |
| 魔修 | 吸血、生命交換 | 血煞、黑袍、詭異 |
| 佛修 | 護盾、淨化 | 金光、袈裟、梵音 |
| 妖修 | 變身、後期成長 | 獸形、靈氣、野性 |
| 散修 | 靈活、萬用 | 樸素、機緣、隨機 |

### 3.3 美術方向

- **整體**：水墨風格化 3D，低多邊形模型搭配墨線描邊 Shader，色彩以留白與少量高飽和點綴（劍光、丹火、雷劫）。
- **玩家角色**：2D 分層立繪，乾淨墨線加柔和賽璐珞上色；所有捏臉配件共用同一段風格描述生成，確保互相拼裝時風格一致。
- **道友辨識**：每個流派固定一個主色與剪影特徵（劍修背劍、丹修持爐、佛修光環），確保縮圖下仍可辨識。
- **境界視覺**：突破後模型不換、但加上「境界光效」（煉氣無光效、築基淡光、金丹金環、元嬰身後虛影）。
- **靈根視覺**：玩家角色身周有靈根色澤的氣息，每條靈根一種色澤，極品明顯、下品幾乎不可見；開靈根與洗髓後即時更新。
- **UI**：宣紙底色、朱印按鈕、豎排標題，功能區維持現代橫向布局。

### 3.4 音樂音效

- BGM：古箏、簫、鼓為主，依階段從清幽轉向緊張。
- 音效關鍵：創角測靈的「骰響 + 測靈石光」、服丹開靈根的「經脈轟鳴」、突破的「鐘鳴」、渡劫的「雷擊」、心魔的「低語」須有極高辨識度。

## 4. 角色創建與捏臉系統

### 4.1 定位

- 角色為 **帳號層級的持久資料**，首次進入遊戲必須創建（可用預設臉，但不可跳過流程）。
- 角色儲存 **外觀、道號、出身、聲線、靈根、屬性配點、局外成長進度**。靈根與屬性在創角時一次決定，之後只能透過局外的丹藥系統改變（見第 6、7、17 章），每局不再重擲。
- 角色是你在棋局中的「本命化身」，也顯示在排行榜與對手畫面。

> **設計決策**：靈根與屬性綁定在角色上，意味著局外成長會影響對局。本作以三件事維持公平：
> 1. **創角時命格評分固定**：靈根越純越高階，自配屬性點數越少；五行廢靈根點數最多。每個新角色的「靈根值 + 屬性點」總和相同（見 6.2）。
> 2. **開靈根與洗髓代價遞增**：第二、第三靈根與品階提升的資源需求陡升，且不可用現金購買（見 6.4）。
> 3. **命格評分配對**：配對與排位依角色的命格評分分層，成長差距大的玩家不會同場（見 17.7）。

### 4.2 創建流程

```
選擇性別與體型 → 捏臉 → 髮型服飾 → 聲線 → 道號 → 出身 → 天道測靈（擲骰靈根） → 自配屬性點 → 完成（進入洞府）
```

預估時間：預設 3 分鐘，深度捏臉與配點 20 分鐘以上。

### 4.3 捏臉系統規格：2D 分層換裝式

捏臉採 **2D 分層換裝**（layered dress-up）：角色立繪由多層透明 PNG 配件疊合而成，玩家逐層挑選款式，再對每一層微調大小、位置與角度。這是《奇蹟暖暖》《原神 Web 活動》《Picrew》等作品驗證過的作法，素材產能高、風格易統一、手機效能負擔低，也最適合用圖像生成工具量產配件。

**圖層順序（由後到前）**

| 序 | 圖層 | 內容 | 首版款式數 |
|---|---|---|---|
| 1 | 背景 | 論道台、靈根氣息、金丹光環 | 6 背景 × 8 氣息 |
| 2 | 後髮 | 頭後與肩側的頭髮（道髻長髮、高馬尾、披髮、短髮、半束髮、光頭等） | 12 |
| 3 | 身體 | 宗門道袍、交領、肩線 | 6 宗派 × 2 |
| 4 | 臉型 | 光頭底臉，含耳、脖子與基礎陰影（瓜子、鵝蛋、圓、方、長、菱形等） | 8 |
| 5 | 眼睛 | 一對眼睛，含眼白、虹膜、睫毛 | 16 |
| 6 | 眉毛 | 一對眉毛 | 10 |
| 7 | 鼻子 | 線稿式鼻子 | 8 |
| 8 | 嘴巴 | 嘴唇與表情 | 10 |
| 9 | 鬚與斑 | 鬍鬚、雀斑、痣、面靨 | 8 |
| 10 | 紋飾 | 花鈿、朱砂、金印、道紋、疤痕 | 10 |
| 11 | 前髮 | 瀏海與鬢髮，含道髻 | 12 |
| 12 | 髮飾 | 髮簪、金冠、髮帶 | 8 |

**每層可微調的項目**

| 項目 | 範圍 | 適用層 |
|---|---|---|
| 大小 | 60% – 150% | 全部 |
| 位置 | 水平、垂直各 ±60 px（以 600×760 基準畫布計） | 全部 |
| 角度 | ±20° | 眼、眉、鼻、嘴、紋飾、髮飾 |
| 間距 | ±30 px（成對配件左右分開） | 眼、眉 |
| 顏色 | 膚色、髮色、瞳色，以色相 / 明度重新著色 | 臉型、前髮、後髮、眼 |

**操作與保存**

- 左側選部位、右側為款式縮圖格；點選即換上，下方滑桿微調。
- **保存**：臉譜庫可存多組；捏臉資料為「各層款式 ID + 微調參數」的短字串，可匯出、匯入與掃碼分享。
- **隨機**：隨機本部位、隨機全臉；隨機結果的微調參數維持預設，避免亂掉。
- **復原**：撤銷 / 重做至少 60 步；按住「對比原貌」可與套用前比較。
- 提供 **20 組預設臉**（六大宗派各 3 組加 2 組通用）。

**素材規格**

- 基準畫布 **1200×1520 px**（4:5），所有配件以此畫布為座標系，輸出透明 PNG。
- 每個配件一個檔案，命名 `圖層_編號.png`（例：`eyes_03.png`、`hairfront_07.png`），另附 `manifest.json` 記錄預設位置、大小與可著色區。
- 配件由 **圖像生成工具製作**（詳見 19.2），再經去背、對位、校準三道工序入庫。
- 首版素材量約 120 件；每季新增 20 – 30 件作為外觀商品。

### 4.4 道號與出身

- **道號**：2–6 字，可重複（以帳號 ID 區分）。
- **出身**（純敘事，不影響數值）：世家子弟、山野孤兒、商賈之後、行伍出身、藥農之子、書香門第。決定測靈時 NPC 的對話、稱號與部分秘境文本。

### 4.5 天道測靈與配點（創角最後兩步）

- **天道測靈**：角色站上測靈石擲「天命骰」，決定靈根命格（靈根數量、各靈根屬性與品階）。可擲 **3 次，從三組結果中任選一組保留**。因為結果永久，採「任選」而非「保留最後一次」，避免創角即後悔。
- **自配屬性點**：依測靈結果獲得對應的自配點數，分配到五大屬性。配點階段可反覆調整，確認後鎖定。
- 靈根規則詳見第 6 章，屬性規則詳見第 7 章。

### 4.6 服飾與外觀成長

- 服飾分 **宗門道袍**（入宗後依宗派自動更換，可關閉）與 **自選服飾**（局外解鎖）。
- 境界光效、突破特效、渡劫雷劫樣式皆為外觀項目，可在洞府設定。
- 靈根數量與品階會反映在角色身周的靈氣色澤上（見 3.3），開靈根後外觀隨之變化。

## 5. 開局流程：入宗、拜師

靈根與屬性已在創角時決定，因此每局的開局流程只剩兩段。全體玩家同步進行，總時限 **75 秒**（每段獨立倒數，逾時採預設）。

```
┌─────────────────┐   ┌─────────────────┐
│ ① 入宗（選宗派） │ → │ ② 拜師（選山長/洞主）│ → 進入回合 1-1
│   30 秒          │   │   45 秒          │
└─────────────────┘   └─────────────────┘
```

- 熟手可一鍵「**沿用上局**」，直接套用上一局的宗派與師父。
- 開局時會向全場展示各玩家的靈根命格（例：「天靈根 · 金」「五行雜靈根」），作為話題與閱讀對手方向的線索。

### 5.1 ① 入宗：選擇金丹宗派

- 六大金丹宗派同時提供入門，玩家擇一。
- 宗派決定：**宗門大陣**（全局被動）、**宗門道友池偏向**（招牌流派的道友出現機率 +）、可拜師的山長 / 洞主名單、宗門道袍外觀。
- 宗派 **不設靈根門檻**，任何命格都能入任何宗派；門檻設在拜師層。

### 5.2 ② 拜師：山長或洞主

- 列出該宗派的掌門、山長、洞主（共 7–8 位），每位顯示：擅長流派、拜師條件、師門傳承（被動效果）。
- 依你的靈根命格與屬性，部分師父會「**願意收徒**」、部分「**婉拒**」。條件清楚顯示，不會有隱藏門檻。因為靈根與屬性固定，你能拜的師父名單在局外也可預覽，並隨開靈根、洗髓而擴大。
- 拜師後獲得：
  1. **師門傳承**：師父專屬被動，貫穿全局。
  2. **商店偏向**：師父擅長流派的道友出現機率提升（1 流派 +10%；2 流派各 +6%；3 流派各 +4%）。
  3. **師父指點**：階段三與階段五各一次，從三個與師父流派相關的增益中選一。
  4. **師父出山**：階段五起，師父本人會以特殊 5 費道友出現在商店一次（唯一、不可合成、有專屬神通）。
- 逾時未選：自動拜入條件最寬鬆、與主靈根最匹配的洞主。

### 5.3 開局流程的設計意圖

| 決策 | 玩家在想什麼 | 對局影響 |
|---|---|---|
| 選哪個宗派 | 我是雷靈根，哪個宗派的雷系道友多？對手都是劍修，我要不要換路？ | 道友池、宗門大陣 |
| 拜山長還是洞主 | 山長會三個流派但條件高；洞主只專一藝但收我 | 起手方向、後期師父出山 |
| 沿用或改變 | 上局這套打不過，這次換個師父試試 | 每局的變化來源 |

## 6. 靈根系統

### 6.1 天道測靈：創角時擲骰一次

靈根在創角時擲骰決定，**永久綁定角色**。擲骰結果稱為「**靈根命格**」，包含靈根數量、各靈根屬性與各靈根品階。

**擲骰結果表（d100）**

| 命格 | 組成 | 機率 | 靈根值 | 自配屬性點 |
|---|---|---|---|---|
| 天靈根 | 極品 ×1 | 3% | 40 | 10 |
| 變異靈根 | 極品變異（雷 / 冰 / 風）×1 | 2% | 40 | 10 |
| 上品單靈根 | 上品 ×1 | 10% | 32 | 18 |
| 上品雙靈根 | 上品 ×1 + 中品 ×1 | 12% | 28 | 22 |
| 中品雙靈根 | 中品 ×2 | 15% | 24 | 26 |
| 中品三靈根 | 中品 ×1 + 下品 ×2 | 18% | 20 | 30 |
| 下品四靈根 | 下品 ×4 | 20% | 14 | 36 |
| 五行雜靈根 | 下品 ×5（俗稱廢靈根） | 20% | 10 | 40 |

- 靈根屬性從金木水火土中不重複抽取；第一個抽到的為「**主靈根**」，其餘為「副靈根」。品階最高者為主靈根。
- 變異靈根的屬性為雷 / 冰 / 風擇一，不附帶五行副靈根。
- 可擲 3 次，任選一組保留（見 4.5）。
- **靈根值 + 自配屬性點 = 50**，每個新角色的命格評分相同。靈根越純越高階，能自由分配的屬性點越少；五行雜靈根靈根值最低，但有最多的自配點。

### 6.2 靈根值與命格評分

- **靈根值**：衡量靈根整體強度的數字。創角時依命格給定，之後透過開靈根、洗髓提升。
- **命格評分 = 靈根值 + 自配屬性點總數**（含局外獲得的額外點數）。
- 創角時所有角色命格評分為 50；成長後上限約 150（五靈根全極品加滿點）。
- 命格評分用於配對分層與排位分組（見 17.7），不直接影響對局數值。

各靈根品階對靈根值的貢獻（用於開靈根與洗髓後的計算）：

| 品階 | 每一靈根的靈根值 |
|---|---|
| 下品 | 2 |
| 中品 | 6 |
| 上品 | 12 |
| 極品 | 22 |

> 註：創角命格的靈根值為設計指定值，並非各靈根值的簡單加總，這是刻意讓「單一純靈根」比「多個雜靈根」評分更高，符合修仙世界觀中「靈根貴精不貴多」的設定。

### 6.3 靈根在對局中的效果

每一條靈根依其品階提供效果，多靈根者的效果各自獨立計算。

| 品階 | 該靈根羈絆門檻 | 商店偏向 | 功法共鳴 | 本命化身 |
|---|---|---|---|---|
| 極品 | -1，且效果 +20% | +12% | +30% | 主靈根神通強化版 |
| 上品 | -1 | +8% | +15% | 主靈根神通標準版 |
| 中品 | 無 | +5% | +10% | 主靈根神通標準版；副靈根附帶一個小被動 |
| 下品 | 無 | +2% | +5% | 主靈根神通削弱版；副靈根附帶一個小被動 |

- **主靈根**決定本命化身的神通（金：劍氣斬、木：回春、水：寒潮、火：焚天、土：地裂、雷：天雷、冰：冰封、風：疾風）。
- **副靈根**各附帶一個小被動（例：木副靈根使本命化身每 5 秒回復 2% 生命；土副靈根使本命化身護體 +10）。
- **靈根數量的特殊效果**：
  - 擁有 **3 條以上靈根**：本命化身可與任一持有靈根屬性的功法共鳴。
  - 擁有 **5 條靈根（五行齊全）**：本命化身獲得「五行輪轉」，戰鬥中每 10 秒切換一次主靈根神通；商店偏向合計 +10%，覆蓋全部五行。
- 變異靈根（雷 / 冰 / 風）的道友稀少但效果極端，該羈絆門檻 -1，本命化身獲得變異神通。
- 各命格的期望強度應接近：極品靠純度與高上限，雜靈根靠屬性點數與廣度。實際數值由平衡模擬器校準（見 19.4）。

### 6.4 開靈根與洗髓（局外成長）

靈根在創角後仍可成長，但只能透過 **丹藥**，且代價隨現有靈根數量與品階陡升。丹藥由洞府的丹房煉製，所需的靈玉與藥材只能透過對局、任務與成就取得，**不可用現金購買**（見第 17、21 章）。

#### 丹藥種類

| 丹藥 | 效果 | 限制 |
|---|---|---|
| **開靈丹** | 開啟一條新靈根（自選五行屬性，起始為下品） | 最多 5 條五行靈根；變異靈根不可透過開靈丹取得 |
| **洗髓丹** | 將一條靈根的品階提升一級（下→中→上→極） | 每條靈根每級一次 |
| **換靈丹** | 更換一條下品靈根的屬性 | 僅限下品；主靈根不可換 |
| **忘塵丹** | 重置全部自配屬性點 | 每 30 天一次 |

#### 開靈丹代價（依開啟後的靈根總數）

| 開啟第幾條靈根 | 靈玉 | 藥材（百草） | 天材地寶 | 概估對局數 |
|---|---|---|---|---|
| 第 2 條 | 3,000 | 50 | 0 | 約 25 局 |
| 第 3 條 | 12,000 | 200 | 1 | 約 100 局 |
| 第 4 條 | 30,000 | 500 | 3 | 約 250 局 |
| 第 5 條 | 70,000 | 1,000 | 8 | 約 600 局 |

- 天靈根與變異靈根玩家從第 2 條開始算；四靈根玩家只需開第 5 條，但仍以「第 5 條」的代價計算。
- 開靈丹只開出 **下品**，要提升品階仍需洗髓丹。這確保「純靈根想變全能」與「雜靈根想變精純」都是漫長的路。

#### 洗髓丹代價（依目標品階）

| 提升 | 靈玉 | 藥材（百草） | 天材地寶 | 額外條件 |
|---|---|---|---|---|
| 下品 → 中品 | 2,000 | 40 | 0 | 無 |
| 中品 → 上品 | 8,000 | 150 | 1 | 該靈根羈絆啟動下進入前四 5 次 |
| 上品 → 極品 | 25,000 | 500 | 5 | 該靈根羈絆啟動下奪冠 3 次 |

- 第 2 條以後的靈根洗髓代價 **×1.5**、第 3 條以後 **×2**、第 4 條以後 **×3**（以開啟順序計）。
- 靈玉收入概估：前四名約 120 / 局、後四名約 50 / 局、每日任務約 150 / 日（見 17.4）。

#### 成長路線示意

| 起手命格 | 常見發展 | 到達「三靈根皆上品」約需 |
|---|---|---|
| 天靈根 | 保持純粹、堆極品效果；或極高代價開第 2 條 | 約 400 局以上 |
| 上品單靈根 | 先洗到極品，再開第 2 條 | 約 300 局 |
| 中品三靈根 | 逐條洗髓，中期即成型 | 約 200 局 |
| 五行雜靈根 | 靠屬性點打前期，逐條洗髓，晚期成為五行全能 | 約 250 局（但可達五靈根） |

### 6.5 逆天改命（局內臨時效果）

局內另有不影響帳號的臨時提升，讓每局仍有「機緣」感：
- 秘境「**洗髓池**」：花費道基 10 點，本局主靈根品階臨時 +1（一局一次；下品主靈根玩家出現率提高）。
- 天劫回合渡劫成功時，額外掉落 5 百草（帶出局外，累積用於煉丹）。

### 6.6 靈根與流派的關係

- 靈根是天生資質（五行 + 變異），流派是後天修煉路數（劍丹符體魔佛妖散），兩者獨立。
- 道友同時具備流派與靈根，因此陣容可以同時追求「劍修 4 + 火靈根 3」這類雙軸羈絆。
- 玩家自身的靈根越多，能自然配合的靈根羈絆越多，但每一條的門檻減免與偏向越弱。

## 7. 屬性系統

### 7.1 五大先天屬性與自配點

五大屬性 **基礎值皆為 10**，創角時依靈根命格獲得 10 – 40 點自配點（見 6.1），分配後永久保存。

**配點規則**

| 屬性區間 | 每提升 1 點所需自配點 |
|---|---|
| 11 – 15 | 1 |
| 16 – 18 | 2 |
| 上限 | 18（創角時） |

- 五行雜靈根的 40 點足以把兩項堆到 18、一項到 15，或平均分配到全部 14–15。
- 天靈根的 10 點只能專精一項到 15 或雙項到 13。

### 7.2 屬性效果

以「修正值 = 屬性 − 10」計算，因基礎值為 10，修正值不會為負。

| 屬性 | 主要影響 | 每點修正值效果 | 門檻效果 |
|---|---|---|---|
| **根骨** | 肉身與生命 | 本命化身生命 +4%、全隊道友生命 +1% | ≥ 15：本命化身免疫擊退 |
| **悟性** | 修煉與功法 | 每回合修為 +0.1（累積成整數）、功法效果 +2% | ≥ 15：師父指點可三選二 |
| **神識** | 洞察與商店 | 道友詳情可看隱藏數值、預覽對手範圍擴大 | ≥ 13：可預覽下回合對手；≥ 16：商店多 1 格 |
| **氣運** | 機緣與天劫 | 渡劫成功率 +1%、秘境高稀有掉落 +2% | ≥ 15：每局一次免費重擲秘境選項 |
| **心性** | 道心與心魔 | 心魔觸發機率 -3%、本命化身靈力回復 +2% | ≥ 15：心魔改為只觸發正面效果 |

- 每點效果刻意設計為「廣而淺」：雜靈根多出的 30 點分散到全隊生命、修為、經濟與渡劫上，對應極品靈根「窄而深」的羈絆與神通強化。

### 7.3 屬性在拜師條件中的角色

- 山長與掌門常設屬性門檻（例如「悟性 ≥ 12」「根骨 ≥ 13」），配點時即可預覽哪些師父會收你。
- 洞主多無門檻或僅要求靈根屬性相符。
- 因為屬性永久，配點等於在創角時就決定了自己偏好的師承路線；忘塵丹可重置。

### 7.4 屬性成長

- **局內（臨時）**：秘境「機緣閣」可能提供「本局某屬性 +2」；渡劫成功時本命化身本局根骨 +1。
- **局外（永久）**：傳承等級每 10 級 +1 自配點，上限 +5（計入命格評分）；忘塵丹可重置配點。除此之外不提供永久屬性成長。

| 山長（御獸峰） | 馭妖山長 | 魔修 / 妖修 | 木靈根，根骨 ≥ 12 | 「血契」：妖修道友每次成長額外 +5%，但每次成長扣 2% 當前生命 |
| 山長（幽冥峰） | 幽冥山長 | 魔修 / 符修 / 體修 | 心性 ≥ 12 | 「幽冥陣」：戰鬥開始時敵方前排持續流血 |
| 洞主（血池洞） | 血池洞主 | 魔修 | 無 | 「血池」：魔修羈絆門檻 -1，但每回合開局本命化身生命 -5% |
| 洞主（煉屍洞） | 煉屍洞主 | 妖修 | 無 | 「屍傀」：第一名死亡的道友以 50% 屬性復活一次，但無法釋放神通 |
| 洞主（斷情洞） | 斷情洞主 | 劍修 / 魔修 | 心性 ≤ 8 | 「斷情絕愛」：劍修道友暴擊率 +25%，但無法被治療 |

> 其餘四派（神農谷、大雷音寺、萬妖山、逍遙居）的完整山長 / 洞主設定另立《宗派與師承設定表》維護。

### 8.4 拜師條件設計原則

| 條件類型 | 用途 |
|---|---|
| 靈根品階 | 掌門與少數山長設此門檻，讓極品 / 上品有專屬選項 |
| 靈根屬性 | 山長多設此門檻，讓靈根命格引導宗派選擇 |
| 屬性門檻 | 分散在不同屬性，使每種配點都有對應的「好師父」 |
| 極端條件 | 如「心性 ≤ 8」，讓低屬性也能開出特色路線 |
| 無條件 | 每派至少 2 位洞主無條件，保證任何命格都有 12 位以上可選師父 |

### 8.5 師父出山（特殊道友）

- 階段五起，師父本人出現在商店一次，費用 5，唯一。
- 屬性略高於一般 5 費，神通對應其擅長流派（多流派師父的神通有多段效果）。
- 師父在場時，師門傳承效果 +50%。
- 賣出後不再出現。

### 9.1 單局結構

開局流程（第 5 章）後進入 **6 個階段（紀元）**，每階段 4 – 6 回合，總計約 30 回合。

|---|---|---|---|
| — | 入道 | 開局流程 | 入宗、拜師 |

| 六 | 渡劫 | 6-1 ~ 結束 | 每回合傷害大幅提升，快速決出勝負 |

### 9.2 回合流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
```

### 9.3 勝負條件

- 每位玩家初始 **道基 100**。
- 道基歸零即出局；最後存活者勝。
- 排名 1–4 為「得道」（正分），5–8 為「道損」（負分）。

### 10.5 本命化身（玩家角色）

- 玩家角色以「本命化身」**常駐棋盤**，不佔上場人數、不可販賣、不可合成。
- 戰鬥中被擊倒只是「退場」，不影響道基扣除計算（不計入存活敵方數量）。
- 屬性隨 **玩家境界** 成長（見 12.2），並受五大屬性修正。
- **神通來源**：主靈根決定基礎神通（金：劍氣斬、木：回春、水：寒潮、火：焚天、土：地裂、雷：天雷、冰：冰封、風：疾風），品階決定強化 / 標準 / 削弱版。
- 本命化身可攜帶 1 件法寶與 1 本功法。
- 設計目的：讓捏臉角色有意義、讓創角時的靈根命格直接體現在戰場上。此機制需在原型階段驗證對平衡的影響。

## 12. 修仙成長系統

成長分四層：**道友成長、玩家成長、功法法寶、師承成長**。

### 12.1 道友成長：突破與渡劫

#### 突破（煉氣→築基→金丹）
- 三合一自動合成，播放「突破」演出（1 秒），保留已裝備的功法法寶。

#### 渡劫（金丹→元嬰）
- 只在 **天劫回合**（4-6、5-6、6-3）可執行，每回合最多 1 名道友。
- 基礎成功率 60%，修正見 23.3。
- **成功**：升為元嬰，隨機獲得一個「劫後神通」；本命化身本局根骨 +1；額外掉落 5 百草帶出局外。
- **失敗**：退回築基，獲得 3 靈石與「道心堅定」標記（下次渡劫 +20%）。

### 12.2 玩家成長：修為與境界

玩家角色自身的修煉，相當於一般自走棋的玩家等級。

| 玩家境界 | 上場人數 | 所需修為 | 本命化身屬性倍率 | 解鎖 |
|---|---|---|---|---|
| 煉氣 | 3 | 0 | 1.0× | — |
| 築基 | 4 | 4 | 1.4× | — |
| 金丹 | 5 | 10 | 1.9× | 悟道神通一 |
| 元嬰 | 6 | 20 | 2.5× | — |
| 化神 | 7 | 36 | 3.2× | 悟道神通二 |
| 煉虛 | 8 | 56 | 4.0× | — |
| 合體 | 9 | 80 | 5.0× | 悟道神通三 |
| 渡劫 | 10 | 120 | 6.5× | 上場人數上限 |

- 每回合自動 +2 修為（悟性修正見 7.2）；花 4 靈石可購買 4 修為（「閉關」）。
- **悟道神通**：三個階段各從三選一中挑一個被動。例如：
  - 金丹期：「識人之明」（商店每次刷新保底一名師父擅長流派的道友）、「點石成金」（利息上限 +2）、「護短」（前排道友護體 +10）。
  - 化神期：「天機」（可預覽下一回合對手）、「煉器」（每 3 回合送一件法寶素材）、「悟道」（隨機一個羈絆門檻 -1）。
  - 合體期：「化身」（複製一名金丹以下道友）、「逆命」（渡劫失敗不降級）、「宗門大陣強化」（宗門大陣效果翻倍）。

### 12.3 功法與法寶

#### 法寶（數值型）
- 由秘境、PvE 回合掉落素材（精鐵、靈玉、妖丹、雷木等），兩件素材合成一件法寶。
- 每名道友最多 3 件；本命化身 1 件。
- 範例：精鐵 + 精鐵 = 玄鐵重劍（攻擊 +30%）；靈玉 + 妖丹 = 護心鏡（致死傷害時護盾一次）；雷木 + 精鐵 = 雷鳴劍（攻擊附帶雷擊，跳躍 2 名敵人）。
- 首版目標：8 種素材、36 種合成法寶。

#### 功法（行為型）
- 稀有取得（秘境深層、天劫回合、師父指點），每名道友最多 1 本（文淵山長傳承可 +1）；本命化身 1 本。
- 功法改變神通行為，例如：《御劍訣》使御劍類神通改為攻擊最近敵人並穿透；《噬魂經》使神通傷害 50% 轉為治療；《太上忘情》使神通改為每 6 秒自動釋放但傷害 -40%。
- **靈根共鳴**：功法有屬性，與道友靈根相同時效果強化。本命化身可與任一持有靈根屬性的功法共鳴（三靈根以上者範圍自然更廣）。
- 首版目標：12 本功法。

### 12.4 師承成長

| 時機 | 內容 |
|---|---|
| 開局 | 師門傳承被動、商店偏向 |
| 3-1 師父指點（一） | 三選一：與師父流派相關的小增益（如「劍修道友攻速 +10%」「下一次秘境必出功法」） |

| 5-1 起 師父出山 | 商店出現師父本人一次（特殊 5 費） |

## 13. 經濟與商店

### 13.1 靈石（貨幣）

- 每回合基礎收入：5 靈石。
- **利息**：每持有 10 靈石 +1，上限 +5（50 靈石）。
- **連勝 / 連敗**：2–3 連 +1、4–5 連 +2、6+ 連 +3。
- 勝利額外 +1。
- PvE 回合掉落素材而非靈石。

### 13.2 商店

- 每回合自動刷新 5 個欄位（神識 ≥ 16 為 6 格）；手動刷新 2 靈石（逍遙居 1 靈石）。
- 可鎖定商店。
- 出現機率依玩家境界變化（見 23.1），再疊加 **宗派偏向**（招牌流派 +3%）、**師父偏向**（1 流派 +10% / 2 流派各 +6% / 3 流派各 +4%）、**靈根偏向**（每條靈根依品階，見 6.3）。

### 13.3 賣出

- 煉氣道友賣出回收原價。
- 築基 / 金丹賣出回收「合成所耗總價 - 1」。
- 元嬰道友賣出回收金丹價，劫後神通消失。
- 師父道友賣出回收 5 靈石，不再出現。

### 13.4 經濟策略空間

- **攢息流**：早期吃利息，中期一波升級。
- **連敗流**：故意輸養連敗收入，同時累積素材。
- **快升級流**：早升玩家境界搶 4 費道友。
- **渡劫賭徒流**：全力堆渡劫成功率，靠元嬰翻盤。
- **雜靈根流**：靠高屬性點的全隊生命與修為優勢打前中期，搭配多靈根羈絆的彈性。

## 14. 戰鬥系統

### 14.1 棋盤

- 六角格棋盤，8 列 × 7 行；己方 4 列、敵方 4 列（鏡像）。
- 備戰區 9 格。
- 本命化身佔一格，可自由擺放，不計入上場人數。

### 14.2 戰鬥規則

- 道友自動尋敵：預設攻擊「射程內最近敵人」，特殊神通可改變目標邏輯。
- 攻擊累積靈力，受傷也累積靈力；靈力滿時釋放神通並歸零。
- 戰鬥最長 60 秒，超時比較雙方剩餘總生命百分比（本命化身不計入），高者勝，敗方扣道基減半。

### 14.3 傷害公式

```
物理傷害 = 攻擊 × (1 + 攻擊加成) × 暴擊倍率 × 100 / (100 + 護體)
法術傷害 = 神通基礎值 × (1 + 法傷加成) × 100 / (100 + 道心)
真實傷害 = 不受護體 / 道心影響
```

### 14.4 道基扣除

```
扣除量 = 階段基礎傷害 + Σ(存活敵方道友境界傷害)
```

| 階段 | 基礎傷害 | 煉氣 | 築基 | 金丹 | 元嬰 |
|---|---|---|---|---|---|
| 二 | 0 | 1 | 2 | 3 | 5 |
| 三 | 2 | 1 | 2 | 3 | 5 |
| 四 | 4 | 2 | 3 | 4 | 6 |
| 五 | 6 | 2 | 3 | 5 | 8 |
| 六 | 10 | 3 | 5 | 7 | 10 |

### 14.5 戰鬥確定性

- 戰鬥必須是**確定性模擬**（相同輸入、相同種子 → 相同結果），伺服器與客戶端跑同一份邏輯，客戶端只負責演出。
- 所有隨機（含創角測靈擲骰）使用伺服器種子的 PRNG，禁止使用系統時間或非確定性浮點運算。

## 15. 局內事件：秘境、天劫、心魔

### 15.1 秘境（每階段第 4 回合）

玩家從 **三個秘境中選一個進入**（全體同時選，各自獨立結算）：

| 秘境 | 風險 | 獎勵傾向 |
|---|---|---|
| 百草嶺 | 低：打靈獸 | 素材 ×2、有機率丹藥（回復道基 10） |
| 劍塚 | 中：打劍靈 | 攻擊向法寶素材、有機率功法 |
| 幽冥淵 | 高：打魔物，戰敗多扣道基 | 保底一本功法或一名 4 費道友 |
| 機緣閣 | 無戰鬥 | 三選一機緣（如「每回合多 1 靈石」「渡劫 +10%」「某屬性 +2」） |
| 洗髓池 | 無戰鬥，花費道基 10 | 本局主靈根品階臨時 +1（一局一次；下品主靈根玩家出現率提高） |
| 藏經洞 | 中：打守洞靈獸 | 保底一本與師父流派相符的功法 |

- 總池約 12 種，每次隨機三個出現；氣運 ≥ 15 可免費重擲一次選項。

### 15.2 天劫回合（4-6、5-6、6-3）

- PvP 前，玩家可選 1 名金丹道友渡劫（見 12.1）。
- 全體玩家同時演出雷劫，成功 / 失敗會廣播。
- 不渡劫者獲得 2 靈石「避劫」補償。

### 15.3 心魔（動態事件）

觸發條件（任一，受心性修正）：
- 連勝 ≥ 5（主靈根極品者 ≥ 4）：「驕心」— 下回合隨機一名道友攻擊 -30%。
- 連敗 ≥ 5：「怯心」— 下回合隨機一名道友無法釋放神通；但同時獲得「破而後立」：若該回合獲勝，全隊永久 +5% 屬性。
- 靈石 ≥ 70 持續 3 回合：「貪心」— 利息暫時歸零 2 回合。
- 渡劫連續失敗 2 次：「執念」— 下一次渡劫必定成功，但該道友生命 -20%。

原則：**心魔永遠附帶一個對應的機會**。心性 ≥ 15 的玩家心魔只觸發正面效果。

## 17. 局外成長與長線留存

### 17.1 原則

- 局外成長分兩類：**外觀與便利性**（不影響對局）與 **靈根 / 屬性成長**（影響對局方向與廣度）。
- 影響對局的成長 **只能靠遊玩取得**，不賣數值、不賣丹藥、不賣靈玉。
- 以 **命格評分配對** 隔開成長差距（見 17.7）。

### 17.2 角色（持久）

- 捏臉、道號、出身、服飾、境界光效、聲線。
- **靈根命格**：創角擲定，透過丹藥成長（第 6 章）。
- **屬性配點**：創角分配，忘塵丹可重置（第 7 章）。
- **命格錄**：記錄創角擲骰的三組結果與最終選擇、歷次開靈根與洗髓的時間，以稱號展示（例：「天生天靈根」「五行歸一者」）。

### 17.3 丹房（煉丹）

- 洞府內的煉丹設施，將 **靈玉 + 藥材（百草）+ 天材地寶** 煉成開靈丹、洗髓丹、換靈丹、忘塵丹。
- 煉丹需真實時間（開靈丹 24 小時、洗髓丹 8 小時），期間丹房不可煉其他丹；不可用現金加速。
- 煉成後在洞府「服丹」，播放開靈根 / 洗髓演出，角色靈氣外觀隨之更新。

### 17.4 局外資源

| 資源 | 取得方式 | 概估收入 |
|---|---|---|
| **靈玉** | 對局名次（第 1 名 200、第 4 名 100、第 8 名 40）、每日 / 每週任務、成就 | 活躍玩家約 1,000 – 1,500 / 日 |
| **百草（藥材）** | 對局中秘境與渡劫帶出、每週任務 | 約 5 – 15 / 局 |
| **天材地寶** | 賽季成就、排位段位獎勵、天道試煉 | 約 3 – 6 / 賽季 |

- 所有資源 **不可交易、不可購買**。

### 17.5 傳承（帳號等級）

- 每局依名次獲得傳承經驗。
- 等級解鎖：服飾、棋盤皮膚、突破特效、頭像框、捏臉額外預設。
- 每 10 級 +1 自配屬性點（上限 +5）。

### 17.6 洞府、賽季、任務與成就

- **洞府**：展示角色、丹房、已解鎖外觀、道友圖鑑、**師承錄**（曾拜過的師父與其評語）、可拜師預覽（依目前靈根與屬性列出各派願收徒的師父）。
- **賽季**：每 3 個月一季，更替約 1/3 道友、部分羈絆與若干山長 / 洞主；賽季主題（例：「妖亂九州」）。排位段位：煉氣 → 築基 → 金丹 → 元嬰 → 化神 → 飛升。
- **任務**：每日 / 每週任務（「拜入神農谷獲勝一次」「以雜靈根進入前四」）給靈玉、百草與傳承經驗。
- **成就**：「一局內渡劫成功 3 次」「以五靈根奪冠」給稱號與天材地寶。

### 17.7 命格評分配對與新手保護

| 命格評分 | 分層名稱 | 說明 |
|---|---|---|
| 50 – 59 | 初入道 | 全部新角色與尚未成長的角色 |
| 60 – 79 | 小成 | 開了第 2 條靈根或洗髓 1–2 次 |
| 80 – 109 | 大成 | 多靈根中高品階 |
| 110 以上 | 圓滿 | 長期玩家 |

- **休閒與排位皆依分層配對**，人數不足時最多向上下一層擴展，並在對局內標示。
- **新手保護**：前 20 局只與「初入道」配對。
- **排位分組**：各分層有獨立天梯，賽季結算依分層發放獎勵，避免「成長就是排位優勢」。
- **平衡目標**：同一分層內，各靈根命格的前四率差距 < 3%（見 19.4）。

## 18. UI / UX 規劃

### 18.1 創角與捏臉畫面

- 左側角色全身預覽（可旋轉、縮放至臉部）；右側分頁（臉型 / 眉眼 / 鼻嘴 / 髮 / 妝飾 / 體型 / 聲線）。

- 支援手機端雙指縮放與滑桿拖曳。

### 18.2 創角測靈與配點畫面

- **測靈**：中央測靈石與骰子演出，三組結果並排顯示靈根（色澤 + 品階印章）與對應自配點數；可擲 3 次後任選一組。
- **配點**：五屬性雷達圖與加減按鈕，右側即時顯示「依此配點可拜的師父」清單，讓配點有明確目標。

### 18.3 開局流程畫面

- **入宗**：六宗派卡片，顯示招牌流派、宗門大陣、可拜師人數（依你的靈根與屬性計算）。
- **拜師**：師父卡片列表，可收徒者亮起、婉拒者灰階並註明缺少的條件；卡片展開顯示師門傳承全文。

### 18.4 對局畫面要素

- 上方：回合 / 階段指示、全體玩家道基與排名列（含各玩家宗派徽記與靈根命格）。
- 左側：已啟動羈絆列表與師門傳承圖示。
- 右側：戰鬥中的傷害統計。
- 下方：商店、靈石、玩家境界與修為條、刷新 / 閉關按鈕。
- 棋盤上方：天劫回合倒數提示。

### 18.5 關鍵易讀性要求

- 道友頭上顯示境界光環與費用色框；本命化身有專屬底座。
- 羈絆數量 hover 顯示下一門檻，含玩家靈根與師承的門檻減免標示。
- 渡劫按鈕上直接顯示當前成功率百分比及各項修正來源。
- 心魔觸發前一回合給予預警圖示。

### 18.6 手機版考量

- 拖曳擺陣、雙擊賣出、長按查看道友詳情。
- 商店固定底部，拇指區操作。
- 捏臉滑桿加大觸控區。

## 19. 技術架構建議

> 本節為建議，最終選型待技術評估。

### 19.1 引擎

| 選項 | 優點 | 缺點 |
|---|---|---|
| **Godot 4（C#）** | 開源免授權、輕量、2D 圖層合成與著色器容易、社群成長快 | 手機端與大型專案案例較少 |
| Unity | 成熟、2D 與 UI 工具鏈完整、跨平台穩定 | 授權費 |

建議：**原型階段用 Godot 4 + C#**，戰鬥、靈根效果與師承邏輯寫成獨立的 .NET 類別庫（無引擎依賴），伺服器直接複用。

### 19.2 捏臉技術：2D 圖層合成與素材生產線

- **合成**：以 Canvas / Sprite 依圖層順序疊繪，每層套用「位移、縮放、旋轉、間距」的仿射變換；成對配件（眼、眉）以中線切半後分別位移實作間距。可著色層以色相 / 明度重新著色，不另出色版素材。
- **資料**：捏臉資料為各層款式 ID 與微調參數的短字串（約 120 bytes），存於帳號並在配對時分發給同局玩家；本命化身在棋盤上以合成後的立繪快取顯示，不重複合成。
- **素材生產線**（每個配件）：
  1. **生成**：以圖像生成工具（例如 GPT 的 imagegen 或 Gemini）依「風格錨」提示詞產出 4×2 配件表，純白背景、正面、同尺寸。
  2. **去背與裁切**：依格線切件、白底轉透明、修邊。
  3. **對位**：貼到 1200×1520 基準畫布的部位預設框，寫入 `manifest.json`。
  4. **校準**：在編輯器的校準面板微調預設位移與縮放，確認與其他層相容後入庫。
- 素材製作規格與各部位提示詞見 `docs/concept/素材製作指南.md`；頭髮類素材以 `docs/concept/素材模板_頭部對位.png` 為對位底圖。
- 原型：`prototype/face-editor-layers/`（2D 圖層合成編輯器，支援直接匯入 PNG 配件）。

### 19.3 系統分層

```
┌────────────────────────────────────────────────────────┐
│ 客戶端 (Godot)                                          │
│  創角捏臉 / UI / 演出 / 輸入  ←→  戰鬥重播器             │
└───────────────┬────────────────────────────────────────┘
                │ WebSocket (指令 / 狀態同步)
┌───────────────▼────────────────────────────────────────┐
│ 對局伺服器 (.NET)                                        │
│  房間管理 / 開局流程狀態機 / 回合狀態機 / 商店 / 經濟       │
│  ┌──────────────────────────────────────────────────┐   │
│  │ Core.Simulation (純 C#，無引擎依賴)                 │   │
│  │  靈根效果 / 屬性 / 師承 / 棋盤 / 羈絆 / 神通 /       │   │
│  │  傷害 / 確定性 PRNG                                │   │
│  └──────────────────────────────────────────────────┘   │
└───────────────┬────────────────────────────────────────┘
                │
┌───────────────▼────────────────────────────────────────┐
│ 後端服務：帳號 / 角色與靈根資料 / 丹房 / 命格評分配對 / 排位  │
└────────────────────────────────────────────────────────┘
```

### 19.4 資料驅動與平衡工具

- 道友、師父、宗派、羈絆、法寶、功法、秘境、心魔、拜師條件全部以資料表定義。
- 神通行為以「效果節點」組合，減少硬寫程式。
- **無頭模擬器**：讓 AI 以不同靈根命格與配點、宗派、師父組合互打數千場，輸出：同一命格評分分層內各命格的前四率（目標差距 < 3%）、各師父選擇率與勝率、流派羈絆勝率，以及開靈根 / 洗髓後跨分層的強度曲線。這是驗證「命格不同，總量相當」支柱的關鍵工具。
- 靈根命格、丹藥代價、配點規則同樣資料驅動，方便依模擬結果調整自配點數與靈根值。

| 風險 | 影響 | 對策 |

| 開局流程拉長單局時間、8 人等待 | 節奏拖沓 | 兩段各設倒數、逾時自動預設；熟手可一鍵「沿用上局」 |
| 靈根命格不平衡（天靈根必勝或雜靈根必輸） | 創角擲骰變成純運氣，玩家重建帳號洗靈根 | 靈根值 + 自配點恆為 50；平衡模擬器監控同分層各命格前四率；上線後每兩週校準自配點數與靈根值 |
| 局外靈根成長造成老玩家碾壓新手 | 新手流失 | 命格評分分層配對、前 20 局新手保護、各分層獨立天梯；開靈根與洗髓代價陡升，成長曲線緩 |
| 玩家為了洗出天靈根反覆創角 | 帳號濫用、數據失真 | 創角測靈 3 擲任選已降低動機；每帳號限一角色，刪角冷卻 7 天；命格評分相同使雜靈根不虧 |
| 丹藥代價過高造成長線目標無感 | 中期流失 | 第 2 條靈根壓在約 25 局內可達成，先給一次「開靈根」的爽感；後續代價才陡升 |
| 系統過多（靈根配點 + 宗派 + 師承 + 境界 + 渡劫 + 功法 + 心魔） | 新手看不懂 | 教學分段；閉關模式先用簡化規則；排位前 5 局關閉心魔與五行相剋；師父卡片用一句話摘要 |
| 約 45 位師父的內容量與平衡量 | 時程與品質 | 首版每派可先做掌門 1 + 山長 2 + 洞主 2，賽季再擴充 |
| 捏臉美術與技術成本 | 時程 | M1 只用預設臉，M2 才上滑桿；水墨風格降低臉部細節需求 |
| 本命化身打亂自走棋平衡 | 對局變質 | M0 就驗證；保底方案是本命化身改為「不參戰的場邊光環」 |
| 與現有自走棋差異不夠 | 市場定位模糊 | 把測靈定命、拜師、渡劫、開靈根做成宣傳主軸；確保第一局就能體驗到 |
| 修仙題材在非華語市場認知度低 | 海外推廣困難 | 首版聚焦華語市場；視覺與機制設計避免依賴文字理解 |
