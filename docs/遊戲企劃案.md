## 1. 專案概述

### 1.1 一句話介紹

**捏出你的修士、擲骰定下靈根、拜入金丹宗派，在八人論道的棋局中招募道友、突破境界、渡過天劫，成就唯一的飛升者。**

### 1.2 核心概念

《問道棋局》是一款以東方修仙為題材的自走棋（Auto Battler）。玩家首次進入遊戲時 **創建屬於自己的修士角色**（捏臉、道號、出身），之後每一局都是一段新的入道之旅：

1. **擲骰定命**：擲骰決定本局的靈根品階（極品 / 上品 / 中品 / 下品）、靈根屬性與五大先天屬性。
2. **入宗拜師**：在幾大金丹宗派中選擇一派，再從該派的山長、洞主中拜一位為師。師父擅長的流派（劍修、丹修、符修、體修……）決定你的起手方向。
3. **論道棋局**：在準備階段招募道友、佈陣、修煉功法，戰鬥階段由道友自動對戰。玩家角色以「本命化身」親自站上棋盤。
4. **修仙成長**：道友要突破境界、渡天劫；玩家自身也在修煉，境界越高能帶的道友越多。

與傳統自走棋的差異在於：**開局不是空白的，而是一次擲骰與抉擇**；**成長不是三合一升星，而是修仙世界觀下的完整體系**。

### 1.3 基本資訊

| 項目 | 內容 |
|---|---|
| 遊戲類型 | 自走棋 / 策略 / 輕度 Roguelike 元素 |
| 題材 | 東方修仙、仙俠 |
| 目標平台 | 第一階段：PC（Steam）；第二階段：iOS / Android（跨平台同步） |
| 遊玩人數 | 8 人論道（標準）、4 人雙修（2v2）、單人閉關（PvE） |
| 單局時長 | 25 – 35 分鐘（含開局擲骰拜師約 2 分鐘） |
| 營運模式 | 免費遊玩 + 外觀付費（不賣數值） |
| 美術風格 | 水墨風 3D 低模（Stylized Low-poly + Ink Shader），角色支援捏臉 |
| 目標分級 | 12+ |

### 1.4 目標客群

- **核心客群**：熟悉《雲頂之弈》《金鏟鏟之戰》《刀塔自走棋》，追求策略深度與陣容變化的玩家（20–35 歲）。
- **次要客群**：修仙小說、仙俠遊戲（《鬼谷八荒》《了不起的修仙模擬器》）愛好者，被「擲靈根、拜師、捏臉」的修仙開局吸引。
- **潛在客群**：喜歡 Roguelike 構築（《殺戮尖塔》）的玩家，被單人閉關模式吸引。

### 1.5 核心賣點（USP）

1. **擲骰定命的修仙開局**：每局擲骰決定靈根與屬性，極品靈根的狂喜與下品靈根的逆天改命都是故事的一部分。
2. **宗派與師承**：選宗派、拜山長或洞主，師父擅長多種流派時，能開出別人沒有的組合。
3. **你的角色親自上場**：捏臉創建的修士以「本命化身」站在棋盤上，隨境界成長，神通來自靈根與師承。
4. **境界突破取代升星**：三合一即突破，金丹升元嬰需渡劫，成功額外強化、失敗損傷。
5. **秘境、天劫、心魔**：局內事件讓每局有清楚的階段感與翻盤點。

## 2. 設計支柱

| 順序 | 支柱 | 說明 |
|---|---|---|
| 1 | **每局都是一段修仙故事** | 從擲骰入道、拜師、煉氣到飛升，要有清楚的階段感、事件感與敘事感。 |
| 2 | **決策深度高於操作** | 買誰、賣誰、拜誰為師、何時渡劫。不加入需要手速的機制。 |
| 3 | **風險與機緣並存** | 擲骰、渡劫、秘境都有可選擇的風險，機率永遠對玩家透明。 |
| 4 | **隨機決定起點，不決定終點** | 擲骰結果改變玩法方向與變異度，各品階期望強度接近；下品靈根有逆天改命的路。 |
| 5 | **易學難精** | 新手 3 局內看懂靈根、流派與突破；老手鑽研師承搭配、功法共鳴與天劫時機。 |

## 3. 世界觀與美術方向

### 3.1 世界觀

- **世界名**：九州靈界。
- **修仙格局**：九州修為以金丹為巔峰，能結成金丹者方可開宗立派，故稱「**金丹宗派**」。宗派內部依山頭分治：**山長** 執掌一峰、學貫數脈；**洞主** 據一洞天、專精一藝。
- **背景**：千年一度的「**問道大會**」開啟，天道降下「**道基**」給各派弟子。弟子們在「**論道棋局**」中集結道友切磋，落敗者道基受損，道基盡毀者失去問道資格；最後留存者將得到唯一的飛升名額。
- **玩家身份**：一名初入道途的年輕修士。每局的擲骰即「天道測靈」，入宗拜師後才踏上棋局。
- **敘事定位**：局內敘事以短句與事件文本呈現（測靈結果、師父評語、秘境介紹、天劫描述、心魔獨白），不強制劇情，不打斷節奏。
- **場景**：棋盤即「論道台」，四周隨局勢階段變化：煉氣期是山門石台、金丹期是雲海仙島、渡劫期是雷雲密佈。

### 3.2 八大流派（修煉路數）

流派是修煉的路數，跨宗派存在。每名道友有 1–2 個流派，山長 / 洞主各自擅長 1–3 個流派。

| 流派 | 定位 | 風格關鍵字 |
|---|---|---|
| 劍修 | 高單體爆發、前排 | 御劍、劍氣、白衣 |
| 丹修 | 治療、增益 | 丹爐、藥香、青衫 |
| 符修 | 遠程法傷、控制 | 符籙、陣法、黃紙 |
| 體修 | 坦克、反傷 | 金身、鐵骨、赤膊 |
| 魔修 | 吸血、生命交換 | 血煞、黑袍、詭異 |
| 佛修 | 護盾、淨化 | 金光、袈裟、梵音 |
| 妖修 | 變身、後期成長 | 獸形、靈氣、野性 |
| 散修 | 靈活、萬用 | 樸素、機緣、隨機 |

### 3.3 美術方向

- **整體**：水墨風格化 3D，低多邊形模型搭配墨線描邊 Shader，色彩以留白與少量高飽和點綴（劍光、丹火、雷劫）。
- **玩家角色**：捏臉系統需在水墨風格下仍保有辨識度，因此臉部細節以「線條」與「色塊」為主，不追求寫實。
- **道友辨識**：每個流派固定一個主色與剪影特徵（劍修背劍、丹修持爐、佛修光環），確保縮圖下仍可辨識。
- **境界視覺**：突破後模型不換、但加上「境界光效」（煉氣無光效、築基淡光、金丹金環、元嬰身後虛影）。
- **靈根視覺**：玩家角色身周有靈根色澤的微弱氣息，極品靈根氣息明顯、下品幾乎不可見。
- **UI**：宣紙底色、朱印按鈕、豎排標題，功能區維持現代橫向布局。

### 3.4 音樂音效

- BGM：古箏、簫、鼓為主，依階段從清幽轉向緊張。
- 音效關鍵：擲骰的「骰響 + 測靈石光」、突破的「鐘鳴」、渡劫的「雷擊」、心魔的「低語」須有極高辨識度。

## 4. 角色創建與捏臉系統

### 4.1 定位

- 角色為 **帳號層級的持久資料**，首次進入遊戲必須創建（可跳過細節用預設臉，但不可跳過流程）。
- 角色決定 **外觀、道號、出身、聲線**，這些是你在棋局中的「本命化身」形象，也顯示在排行榜與對手畫面。
- 角色 **不儲存靈根與屬性**：靈根與屬性每局擲骰決定（見第 5、6、7 章），確保排位公平；角色只記錄「歷史最佳擲骰」作為收藏。

> **設計決策**：曾考慮讓靈根在創角時一次擲定並永久保存。但這會使 PvP 對局不公平，且玩家會反覆重建帳號洗靈根。改為每局擲骰後，「擲靈根」的興奮感每局都有，且擲骰結果直接影響本局拜師與陣容選擇，策略價值更高。此決策列入 23.5 待決事項供討論。

### 4.2 創建流程

```
選擇性別與體型 → 捏臉 → 髮型服飾 → 聲線 → 道號 → 出身 → 完成（進入洞府）
```

預估時間：預設 2 分鐘，深度捏臉 15 分鐘以上。

### 4.3 捏臉系統規格

| 區塊 | 可調項目 | 方式 |
|---|---|---|
| 臉型 | 臉長、臉寬、下顎、顴骨、下巴 | 滑桿（BlendShape） |
| 眉 | 眉型 12 種、眉高、眉距、眉濃 | 預設 + 滑桿 |
| 眼 | 眼型 16 種、眼距、眼高、眼角、眼大小、瞳色 | 預設 + 滑桿 + 色盤 |
| 鼻 | 鼻型 10 種、鼻高、鼻寬、鼻長 | 預設 + 滑桿 |
| 嘴 | 嘴型 12 種、嘴寬、嘴厚、嘴角 | 預設 + 滑桿 |
| 膚色 | 色盤 | 色盤 |
| 髮型 | 40 種（含道髻、披髮、光頭、僧髮） | 預設 |
| 髮色 | 色盤 + 挑染 | 色盤 |
| 鬍鬚 | 12 種 | 預設 |
| 妝容 / 紋飾 | 眼妝、唇色、額飾（花鈿）、道紋、疤痕 | 預設 + 色盤 |
| 體型 | 高矮、胖瘦、肩寬（三段） | 滑桿 |
| 聲線 | 8 種（男 4 女 4），可調音高 | 預設 + 滑桿 |

- 提供 **20 組預設臉** 與 **隨機捏臉** 按鈕。
- 支援 **匯出 / 匯入捏臉代碼**（字串），方便玩家分享。
- 首版目標：滑桿 40 個、預設項目共約 150 個。

### 4.4 道號與出身

- **道號**：2–6 字，可重複（以帳號 ID 區分）。
- **出身**（純敘事，不影響數值）：世家子弟、山野孤兒、商賈之後、行伍出身、藥農之子、書香門第。決定開局測靈時 NPC 的對話、稱號與部分秘境文本。

### 4.5 服飾與外觀成長

- 服飾分 **宗門道袍**（入宗後依宗派自動更換，可關閉）與 **自選服飾**（局外解鎖）。
- 境界光效、突破特效、渡劫雷劫樣式皆為外觀項目，可在洞府設定。

## 5. 開局流程：擲骰、入宗、拜師

每局配對成功後、正式進入回合前，全體玩家同步進行以下三段流程，總時限 **120 秒**（每段有獨立倒數，逾時採預設）。

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│ ① 天道測靈（擲骰）│ → │ ② 入宗（選宗派） │ → │ ③ 拜師（選山長/洞主）│ → 進入回合 1-1
│   45 秒          │   │   30 秒          │   │   45 秒          │
└─────────────────┘   └─────────────────┘   └─────────────────┘
```

### 5.1 ① 天道測靈：擲骰

- 玩家角色站上測靈石，擲出「**天命骰**」，一次擲出：靈根品階、靈根屬性、五大屬性。
- 擲骰演出約 3 秒，結果以「靈根 + 屬性面板」呈現。
- **洗髓（重擲）**：每局可重擲 **2 次**（共 3 次擲骰），**重擲後前一次結果消失**，必須保留最後一次。這是本局第一個風險決策。
- 對局中會廣播誰擲出極品靈根（社交壓力與話題點）。
- 詳細擲骰規則見第 6、7 章。

### 5.2 ② 入宗：選擇金丹宗派

- 六大金丹宗派同時提供入門，玩家擇一。
- 宗派決定：**宗門大陣**（全局被動）、**宗門道友池偏向**（該宗派招牌流派的道友出現機率 +）、可拜師的山長 / 洞主名單、宗門道袍外觀。
- 宗派 **不設靈根門檻**，任何擲骰結果都能入任何宗派；門檻設在拜師層。

### 5.3 ③ 拜師：山長或洞主

- 列出該宗派的掌門、山長、洞主（共 7–8 位），每位顯示：擅長流派、拜師條件、師門傳承（被動效果）。
- 依你的靈根品階、屬性與靈根屬性，部分師父會「**願意收徒**」、部分「**婉拒**」。條件清楚顯示，不會有隱藏門檻。
- 拜師後獲得：
  1. **師門傳承**：師父專屬被動，貫穿全局。
  2. **商店偏向**：師父擅長流派的道友出現機率提升（1 流派 +10%；2 流派各 +6%；3 流派各 +4%）。
  3. **師父指點**：階段三與階段五各一次，從三個與師父流派相關的增益中選一。
  4. **師父出山**：階段五起，師父本人會以特殊 5 費道友出現在商店一次（唯一、不可合成、有專屬神通）。
- 逾時未選：自動拜入條件最寬鬆、與擲骰靈根最匹配的洞主。

### 5.4 開局流程的設計意圖

| 決策 | 玩家在想什麼 | 對局影響 |
|---|---|---|
| 要不要重擲 | 現在這個中品火靈根穩，但賭一次會不會出極品？ | 靈根品階、屬性分佈 |
| 選哪個宗派 | 我擲出雷靈根，哪個宗派的雷系道友多？ | 道友池、宗門大陣 |
| 拜山長還是洞主 | 山長會三個流派但條件高；洞主只專一藝但收我 | 起手方向、後期師父出山 |

## 6. 靈根系統

### 6.1 擲骰規則

靈根由三步骰決定（伺服器擲骰，客戶端演出）：

**第一步：品階（d100）**

| 品階 | 機率 | 說明 |
|---|---|---|
| 極品 | 5% | 天靈根或變異靈根 |
| 上品 | 20% | 單靈根或雙靈根 |
| 中品 | 45% | 雙靈根或三靈根 |
| 下品 | 30% | 四靈根或五靈根（雜靈根） |

**第二步：靈根數量（依品階擲 d6）**

| 品階 | d6 = 1–2 | d6 = 3–4 | d6 = 5–6 |
|---|---|---|---|
| 極品 | 天靈根（單一屬性） | 天靈根 | 變異靈根（雷 / 冰 / 風擇一） |
| 上品 | 單靈根 | 單靈根 | 雙靈根 |
| 中品 | 雙靈根 | 雙靈根 | 三靈根 |
| 下品 | 四靈根 | 四靈根 | 五靈根 |

**第三步：靈根屬性（從金木水火土中不重複抽取）**

- 多靈根時，第一個抽到的為「**主靈根**」，其餘為「副靈根」。
- 變異靈根另有專屬屬性（雷、冰、風），並附帶一個五行副靈根。

### 6.2 靈根效果

靈根影響三件事：**羈絆門檻、商店偏向、本命化身神通**。

| 品階 | 羈絆門檻 | 商店偏向 | 本命化身 | 補償 / 特殊 |
|---|---|---|---|---|
| 極品 | 主靈根羈絆門檻 -1，且該羈絆效果 +15% | 主靈根道友 +12% | 神通強化版，靈根共鳴功法效果 +30% | 無補償；心魔「驕心」觸發門檻降低（連勝 ≥ 4） |
| 上品 | 主靈根羈絆門檻 -1 | 主靈根 +10%、副靈根 +4% | 神通標準版 | 無 |
| 中品 | 主靈根羈絆門檻 -1（僅一個） | 每個靈根 +5% | 神通標準版 | 開局 +2 靈石 |
| 下品 | 無門檻減免 | 每個靈根 +3% | 神通削弱版，但**任何靈根的功法都能共鳴**（雜靈根萬法皆通） | 開局 +5 靈石；階段二起每回合 +1 靈石；免疫第一次心魔；可在秘境「洗髓池」提升品階 |

- **變異靈根（雷 / 冰 / 風）**：對應羈絆的道友稀少但效果極端，變異靈根玩家該羈絆門檻 -1，且本命化身獲得變異神通。
- **設計目標**：各品階期望強度接近，但 **極品高上限、下品高靈活與高經濟**。實際數值由平衡模擬器校準（見 19.4）。

### 6.3 逆天改命

- 秘境「**洗髓池**」（下品 / 中品玩家專屬出現機率提高）：花費道基 10 點，提升靈根品階一級（一局一次）。
- 天劫回合渡劫成功時，若玩家靈根為下品，有 30% 機率「劫雷洗髓」提升一級。
- 提供下品玩家明確的敘事與機制上的「逆襲」路線。

### 6.4 靈根與流派的關係

- 靈根是天生資質（五行 + 變異），流派是後天修煉路數（劍丹符體魔佛妖散），兩者獨立。
- 道友同時具備流派與靈根，因此陣容可以同時追求「劍修 4 + 火靈根 3」這類雙軸羈絆。

## 7. 屬性系統

### 7.1 五大先天屬性

與靈根同時擲出，每項 **3d6（3–18）**，10 為常人水準。屬性以「修正值 = 屬性 − 10」計算效果。

| 屬性 | 主要影響 | 每點修正值效果 | 門檻效果 |
|---|---|---|---|
| **根骨** | 肉身與生命 | 本命化身生命 +4%、全隊道友生命 +1% | ≥ 15：本命化身免疫擊退 |
| **悟性** | 修煉與功法 | 每回合修為 +0.1（每 10 點修正累積成 +1 修為）、功法效果 +2% | ≥ 15：師父指點可三選二 |
| **神識** | 洞察與商店 | 商店刷新費用 -0（不影響）、道友詳情可看隱藏數值 | ≥ 13：可預覽下回合對手；≥ 16：商店多 1 格 |
| **氣運** | 機緣與天劫 | 渡劫成功率 +1%、秘境高稀有掉落 +2% | ≥ 15：每局一次免費重擲秘境選項 |
| **心性** | 道心與心魔 | 心魔觸發機率 -3%、本命化身靈力回復 +2% | ≥ 15：心魔改為只觸發正面效果 |

- 修正值為負時同比例扣減（例如根骨 7 → 本命化身生命 -12%）。
- **點數補償**：五項總和低於 45 時，每少 1 點開局 +1 靈石（上限 +10），並獲得稱號「寒門」（純敘事）。

### 7.2 屬性在拜師條件中的角色

- 山長與掌門常設屬性門檻（例如「悟性 ≥ 12」「根骨 ≥ 13」），讓擲骰結果直接影響可拜的師父。
- 洞主多無門檻或僅要求靈根屬性相符。

### 7.3 屬性成長

- 局內：秘境「機緣閣」可能提供「+2 某屬性」的機緣；渡劫成功時本命化身根骨 +1。
- 局外：**不提供**永久屬性成長，維持公平。

## 12. 修仙成長系統

成長分四層：**道友成長、玩家成長、功法法寶、師承成長**。

### 12.1 道友成長：突破與渡劫

#### 突破（煉氣→築基→金丹）
- 三合一自動合成，播放「突破」演出（1 秒），保留已裝備的功法法寶。

#### 渡劫（金丹→元嬰）
- 只在 **天劫回合**（4-6、5-6、6-3）可執行，每回合最多 1 名道友。
- 基礎成功率 60%，修正見 23.3。
- **成功**：升為元嬰，隨機獲得一個「劫後神通」；玩家本命化身根骨 +1；下品靈根玩家 30% 機率劫雷洗髓。
- **失敗**：退回築基，獲得 3 靈石與「道心堅定」標記（下次渡劫 +20%）。

### 12.2 玩家成長：修為與境界

玩家角色自身的修煉，相當於一般自走棋的玩家等級。

| 玩家境界 | 上場人數 | 所需修為 | 本命化身屬性倍率 | 解鎖 |
|---|---|---|---|---|
| 煉氣 | 3 | 0 | 1.0× | — |
| 築基 | 4 | 4 | 1.4× | — |
| 金丹 | 5 | 10 | 1.9× | 悟道神通一 |
| 元嬰 | 6 | 20 | 2.5× | — |
| 化神 | 7 | 36 | 3.2× | 悟道神通二 |
| 煉虛 | 8 | 56 | 4.0× | — |
| 合體 | 9 | 80 | 5.0× | 悟道神通三 |
| 渡劫 | 10 | 120 | 6.5× | 上場人數上限 |

- 每回合自動 +2 修為（悟性修正見 7.1）；花 4 靈石可購買 4 修為（「閉關」）。
- **悟道神通**：三個階段各從三選一中挑一個被動。例如：
  - 金丹期：「識人之明」（商店每次刷新保底一名師父擅長流派的道友）、「點石成金」（利息上限 +2）、「護短」（前排道友護體 +10）。
  - 化神期：「天機」（可預覽下一回合對手）、「煉器」（每 3 回合送一件法寶素材）、「悟道」（隨機一個羈絆門檻 -1）。
  - 合體期：「化身」（複製一名金丹以下道友）、「逆命」（渡劫失敗不降級）、「宗門大陣強化」（宗門大陣效果翻倍）。

### 12.3 功法與法寶

#### 法寶（數值型）
- 由秘境、PvE 回合掉落素材（精鐵、靈玉、妖丹、雷木等），兩件素材合成一件法寶。
- 每名道友最多 3 件；本命化身 1 件。
- 範例：精鐵 + 精鐵 = 玄鐵重劍（攻擊 +30%）；靈玉 + 妖丹 = 護心鏡（致死傷害時護盾一次）；雷木 + 精鐵 = 雷鳴劍（攻擊附帶雷擊，跳躍 2 名敵人）。
- 首版目標：8 種素材、36 種合成法寶。

#### 功法（行為型）
- 稀有取得（秘境深層、天劫回合、師父指點），每名道友最多 1 本（文淵山長傳承可 +1）；本命化身 1 本。
- 功法改變神通行為，例如：《御劍訣》使御劍類神通改為攻擊最近敵人並穿透；《噬魂經》使神通傷害 50% 轉為治療；《太上忘情》使神通改為每 6 秒自動釋放但傷害 -40%。
- **靈根共鳴**：功法有屬性，與道友靈根相同時效果強化。下品靈根玩家的本命化身可與任何功法共鳴。
- 首版目標：12 本功法。

## 13. 經濟與商店

### 13.1 靈石（貨幣）

- 每回合基礎收入：5 靈石。
- **利息**：每持有 10 靈石 +1，上限 +5（50 靈石）。
- **連勝 / 連敗**：2–3 連 +1、4–5 連 +2、6+ 連 +3。
- 勝利額外 +1。
- 靈根品階補償與屬性點數補償見第 6、7 章。
- PvE 回合掉落素材而非靈石。

### 13.2 商店

- 每回合自動刷新 5 個欄位（神識 ≥ 16 為 6 格）；手動刷新 2 靈石（逍遙居 1 靈石）。
- 可鎖定商店。
- 出現機率依玩家境界變化（見 23.1），再疊加 **宗派偏向**（招牌流派 +3%）、**師父偏向**（1 流派 +10% / 2 流派各 +6% / 3 流派各 +4%）、**靈根偏向**（見 6.2）。

### 13.3 賣出

- 煉氣道友賣出回收原價。
- 築基 / 金丹賣出回收「合成所耗總價 - 1」。
- 元嬰道友賣出回收金丹價，劫後神通消失。
- 師父道友賣出回收 5 靈石，不再出現。

### 13.4 經濟策略空間

- **攢息流**：早期吃利息，中期一波升級。
- **連敗流**：故意輸養連敗收入，同時累積素材。
- **快升級流**：早升玩家境界搶 4 費道友。
- **渡劫賭徒流**：全力堆渡劫成功率，靠元嬰翻盤。
- **下品逆襲流**：靠下品經濟補償快速滾雪球，再洗髓提升品階。

## 14. 戰鬥系統

### 14.1 棋盤

- 六角格棋盤，8 列 × 7 行；己方 4 列、敵方 4 列（鏡像）。
- 備戰區 9 格。
- 本命化身佔一格，可自由擺放，不計入上場人數。

### 14.2 戰鬥規則

- 道友自動尋敵：預設攻擊「射程內最近敵人」，特殊神通可改變目標邏輯。
- 攻擊累積靈力，受傷也累積靈力；靈力滿時釋放神通並歸零。
- 戰鬥最長 60 秒，超時比較雙方剩餘總生命百分比（本命化身不計入），高者勝，敗方扣道基減半。

### 14.3 傷害公式

```
物理傷害 = 攻擊 × (1 + 攻擊加成) × 暴擊倍率 × 100 / (100 + 護體)
法術傷害 = 神通基礎值 × (1 + 法傷加成) × 100 / (100 + 道心)
真實傷害 = 不受護體 / 道心影響
```

### 14.4 道基扣除

```
扣除量 = 階段基礎傷害 + Σ(存活敵方道友境界傷害)
```

| 階段 | 基礎傷害 | 煉氣 | 築基 | 金丹 | 元嬰 |
|---|---|---|---|---|---|
| 二 | 0 | 1 | 2 | 3 | 5 |
| 三 | 2 | 1 | 2 | 3 | 5 |
| 四 | 4 | 2 | 3 | 4 | 6 |
| 五 | 6 | 2 | 3 | 5 | 8 |
| 六 | 10 | 3 | 5 | 7 | 10 |

### 14.5 戰鬥確定性

- 戰鬥必須是**確定性模擬**（相同輸入、相同種子 → 相同結果），伺服器與客戶端跑同一份邏輯，客戶端只負責演出。
- 所有隨機（含開局擲骰）使用伺服器種子的 PRNG，禁止使用系統時間或非確定性浮點運算。

## 15. 局內事件：秘境、天劫、心魔

### 15.1 秘境（每階段第 4 回合）

玩家從 **三個秘境中選一個進入**（全體同時選，各自獨立結算）：

| 秘境 | 風險 | 獎勵傾向 |
|---|---|---|
| 百草嶺 | 低：打靈獸 | 素材 ×2、有機率丹藥（回復道基 10） |
| 劍塚 | 中：打劍靈 | 攻擊向法寶素材、有機率功法 |
| 幽冥淵 | 高：打魔物，戰敗多扣道基 | 保底一本功法或一名 4 費道友 |
| 機緣閣 | 無戰鬥 | 三選一機緣（如「每回合多 1 靈石」「渡劫 +10%」「某屬性 +2」） |
| 洗髓池 | 無戰鬥，花費道基 10 | 靈根品階 +1（一局一次；中品 / 下品玩家出現率提高） |
| 藏經洞 | 中：打守洞靈獸 | 保底一本與師父流派相符的功法 |

- 總池約 12 種，每次隨機三個出現；氣運 ≥ 15 可免費重擲一次選項。

### 15.2 天劫回合（4-6、5-6、6-3）

- PvP 前，玩家可選 1 名金丹道友渡劫（見 12.1）。
- 全體玩家同時演出雷劫，成功 / 失敗會廣播。
- 不渡劫者獲得 2 靈石「避劫」補償。

### 15.3 心魔（動態事件）

觸發條件（任一，受心性修正）：
- 連勝 ≥ 5（極品靈根 ≥ 4）：「驕心」— 下回合隨機一名道友攻擊 -30%。
- 連敗 ≥ 5：「怯心」— 下回合隨機一名道友無法釋放神通；但同時獲得「破而後立」：若該回合獲勝，全隊永久 +5% 屬性。
- 靈石 ≥ 70 持續 3 回合：「貪心」— 利息暫時歸零 2 回合。
- 渡劫連續失敗 2 次：「執念」— 下一次渡劫必定成功，但該道友生命 -20%。

原則：**心魔永遠附帶一個對應的機會**。下品靈根玩家免疫第一次心魔；心性 ≥ 15 的玩家心魔只觸發正面效果。

## 19. 技術架構建議

> 本節為建議，最終選型待技術評估。

### 19.1 引擎

| 選項 | 優點 | 缺點 |
|---|---|---|
| **Godot 4（C#）** | 開源免授權、輕量、支援 BlendShape 捏臉、社群成長快 | 手機端與大型專案案例較少 |
| Unity | 成熟、捏臉相關資源多、跨平台穩定 | 授權費、風格化渲染需自製 |

建議：**原型階段用 Godot 4 + C#**，戰鬥與開局擲骰邏輯寫成獨立的 .NET 類別庫（無引擎依賴），伺服器直接複用。

### 19.2 捏臉技術

- 臉部以 **BlendShape（Morph Target）** 實作滑桿，預設項目以 **模型替換**（髮型、鬍鬚）與 **貼圖疊層**（妝容、道紋、疤痕）實作。
- 捏臉資料序列化為固定長度數值陣列（約 200 bytes），儲存在帳號並在配對時分發給同局玩家；捏臉代碼即此陣列的 Base64。
- 對局中其他玩家的本命化身以 LOD 降階顯示，避免 8 個捏臉模型同時全量渲染。

### 19.3 系統分層


### 19.4 資料驅動與平衡工具

- 道友、師父、宗派、羈絆、法寶、功法、秘境、心魔、拜師條件全部以資料表定義。
- 神通行為以「效果節點」組合，減少硬寫程式。
- **無頭模擬器**：讓 AI 以不同擲骰結果、宗派、師父組合互打數千場，輸出：各靈根品階勝率（目標：各品階前四率差距 < 3%）、各師父選擇率與勝率、流派羈絆勝率。這是驗證「隨機決定起點不決定終點」支柱的關鍵工具。

## 21. 商業模式

### 21.1 原則

- **免費遊玩、只賣外觀、不賣數值**。靈根、屬性、師父、道友一律不可用現金影響。

### 21.2 付費內容

| 類別 | 範例 | 價格帶 |
|---|---|---|
| 服飾 | 各宗派高階道袍、江湖裝、節慶服 | 中 |
| 捏臉擴充 | 額外髮型包、妝飾包、聲線包 | 低中 |
| 棋盤 / 論道台 | 場景主題（雲海、地宮、雪山） | 中高 |
| 突破 / 渡劫 / 測靈特效 | 突破光效、雷劫樣式、擲骰骰子外觀 | 低中 |
| 道友皮膚 | 特定道友的另一套形象 | 低 |
| 賽季通行證 | 每季主題外觀組合，含免費軌與付費軌 | 固定 |

捏臉系統使「玩家角色外觀」成為主要付費軸，與「不賣數值」原則相容。

### 21.3 營收預估口徑

- 付費率、ARPPU、賽季通行證轉換率待 Beta 資料校準。

## 22. 風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| 開局流程拉長單局時間、8 人等待 | 節奏拖沓 | 三段各設倒數、逾時自動預設；熟手可一鍵「沿用上局選擇」 |
| 靈根品階不平衡（極品必勝或下品必輸） | 擲骰變成純運氣，排位流失 | 平衡模擬器監控品階前四率；下品經濟補償、洗髓池、萬法共鳴等機制；上線後每兩週校準 |
| 系統過多（擲骰 + 宗派 + 師承 + 境界 + 渡劫 + 功法 + 心魔） | 新手看不懂 | 教學分段；閉關模式先用簡化規則；排位前 5 局關閉心魔與五行相剋；師父卡片用一句話摘要 |
| 約 45 位師父的內容量與平衡量 | 時程與品質 | 首版每派可先做掌門 1 + 山長 2 + 洞主 2，賽季再擴充 |
| 捏臉美術與技術成本 | 時程 | M1 只用預設臉，M2 才上滑桿；水墨風格降低臉部細節需求 |
| 本命化身打亂自走棋平衡 | 對局變質 | M0 就驗證；保底方案是本命化身改為「不參戰的場邊光環」 |
| 與現有自走棋差異不夠 | 市場定位模糊 | 把擲骰入道、拜師、渡劫做成宣傳主軸；確保第一局就能體驗到 |
| 修仙題材在非華語市場認知度低 | 海外推廣困難 | 首版聚焦華語市場；視覺與機制設計避免依賴文字理解 |
